Heavy-tailed neuronal connectivity arises from Hebbian self-organization

Christopher W. Lynn, Caroline M. Holmes, Stephanie E. Palmer Nature Physics 2024 Hebbian self-organization, Heavy-tailed connectivity, Neuronal connectomes, Statistical physics, Network Evolution, Clustering

一、论文研究方向、所属领域、相关研究课题

1. 所属领域

跨学科交叉领域，核心包含计算神经科学、网络物理学、统计物理、连接组学（Connectomics）、复杂系统自组织理论，发表于《Nature Physics》，属于物理学顶刊下生物物理/神经物理分支。

2. 研究方向

围绕神经元网络突触连接的重尾分布（幂律无标度）、网络聚类两大核心结构特征，构建极简自组织动力学模型，解释跨物种通用神经布线规律： 1）实证果蝇、线虫、多毛蠕虫、小鼠视网膜等无脊椎/脊椎动物连接组普遍存在突触强度重尾分布； 2）提出无神经元活动的极简模型：随机修剪+偏好增长混合动力学，仅单参数p（偏好增长概率）即可解析推导幂律连接强度分布，幂指数γ=1+1/p； 3）引入神经元活动与赫布可塑性扩展模型，通过神经元活动协方差调控突触生长，自然复现真实神经网络的高聚类三角结构； 4）证明重尾、聚类两大神经网络核心特征无需物种特异性生物机制，仅依靠通用网络自组织规则即可涌现。

3. 相关研究课题

  1. 神经连接组结构统计特性观测：电镜重构全脑/局部神经环路突触分布、功能钙成像神经元活动相关性分布；
  2. 复杂网络偏好依附（富者愈富）无标度网络理论；
  3. 赫布可塑性、时序依赖可塑性（STDP）等突触可塑性动力学建模；
  4. 伊辛平均场模型、涨落耗散定理用于神经元群体活动与协方差解析；
  5. 生物网络稀疏性、异质性、聚类系数等拓扑量化；
  6. 神经网络自组织、脑网络物理与动力学机制。

摘要

这篇发表在《Nature Physics》上的论文名为《Heavy-tailed neuronal connectivity arises from Hebbian self-organization》，探讨了神经元连接强度呈现**重尾分布（heavy-tailed）**这一普遍现象背后的简洁机制。

以下是根据来源整理的论文核心亮点、方法论及模型推导过程：

1. 论文核心亮点 (Highlights)

  • 普适性发现：通过分析果蝇、圆线虫、环节动物及小鼠等多种生物的连通图（connectomes），确认神经元连接强度具有类似的**渐近无标度（asymptotically scale-free）**特性，即极少数连接极强，而绝大多数极弱。
  • 极简解释模型：提出一个基于自组织原理的极简模型。该模型证明，无需复杂的生物物理过程，仅通过随机修剪和“偏好+随机增长”的混合动力学，即可产生真实大脑中的重尾连通性。
  • 赫布学习解释聚类：将模型扩展至包含神经元活动及**赫布可塑性（Hebbian plasticity）**后，发现神经科学中另一个基本特征——**网络聚类（Clustering）**也会自然显现。
  • 统一框架：为研究神经系统结构的演化提供了一个物理学框架，表明连通性的重尾和聚类特征可能源于普遍的网络自组织原则，而非特定物种的生物学约束。

2. 方法论 (Methodology)

  • 数据来源：利用高通量电子显微镜和图像处理生成的多种动物连通图数据，包括果蝇中心脑、果蝇视髓质、C. elegans 全连通图、Platynereis 感觉运动回路及小鼠视网膜数据。
  • 网络建模：
    • 活动无关模型（Activity-independent）：研究连接强度的统计分布。
    • 活动相关模型（Activity-dependent）：结合均值场伊辛模型（mean-field Ising model）模拟神经元活动，通过涨落-耗散定理推导神经元间的协方差（活动相关性）。
  • 参数拟合：仅使用一到两个自由参数（偏好增长概率 $p$ 和相互作用强度 $\beta$）对真实生物网络进行拟合，验证模型对真实连接分布和聚类系数的预测能力。

3. 模型基本定义

该模型将网络定义为由 $n$ 个神经元组成的矩阵 $A$，其中 $A_{ij}$ 表示从神经元 $i$ 到 $j$ 的有向连接强度。

  • 更新规则：
    1. 随机修剪：在每个时间步，随机选择一个连接将其强度清零（$A_{ij} \rightarrow 0$）。
    2. 强度重新分配：将被修剪掉的强度单位重新分配给一对新的神经元。
      • 偏好增长（概率 $p$）：以与当前连接强度 $A_{ij}$ 成正比的概率选择一个连接进行增长。
      • 随机增长（概率 $1-p$）：随机选择一对神经元进行增长。
  • 赫布扩展：在活动相关模型中，“偏好增长”被替换为“赫布增长”——即以与两个神经元之间的活动协方差 $C_{ij}$ 成正比的概率进行增长。

4. 主要推导方法

  • 主方程法（Master Equation）：
    • 通过编写描述连接强度分布 $P(s)$ 随时间变化的递归方程，推导出稳态分布。
    • 稳态分布公式：$P(s) \propto \frac{\Gamma [s + \bar{s}(\frac{1}{p}-1)]}{\Gamma [s + \bar{s}(\frac{1}{p}-1) + 1 + \frac{1}{p}]}$，其中 $\bar{s}$ 为平均连接强度，$\Gamma$ 为欧拉伽马函数。
    • 幂律指数：在强连接极限下（$s \gg \bar{s}/p$），分布呈现幂律形式 $P(s) \approx s^{-\gamma}$，其中幂律指数 $\gamma = 1 + 1/p$，这表明重尾的程度仅取决于偏好增长的比例。
  • 涨落-耗散定理（Fluctuation-dissipation Theorem）：
    • 为了在活动相关模型中计算 $C_{ij}$，作者使用了统计物理中的涨落-耗散定理。
    • 推导出协方差矩阵的闭合解：$C = \beta(I - \beta DA)^{-1}D$，其中 $D$ 是与神经元平均活动相关的对角矩阵。
    • 通过对该公式进行弱相互作用展开（$\beta \ll 1$），可以观察到赫布学习在一阶上强化现有连接（等同于偏好增长），而在二阶上形成三角形（形成聚类）。

本研究提出了一个关于神经元连接自组织的极简模型，旨在解释真实大脑中普遍存在的**重尾分布（heavy-tailed distribution）和聚类（clustering）特征。该模型分为活动无关（Activity-independent）和活动相关（Activity-dependent/Hebbian）**两个阶段进行数学构建与推导。

1. 模型基本定义

模型考虑一个由 $n$ 个神经元组成的网络，其结构由连接矩阵 $A$ 定义，其中 $A_{ij}$ 表示从神经元 $i$ 到 $j$ 的有向连接强度。网络中总连接强度为 $S = \sum_{ij} A_{ij}$，平均连接强度为 $\bar{s} = S / [n(n-1)]$。

网络的演化遵循以下核心规则：

  • 随机修剪（Random Pruning）：每个时间步随机选择一个现有连接并将其强度清零（$A_{ij} \rightarrow 0$）。
  • 强度重分配：被修剪掉的强度单位被重新分配给一对新的神经元。
    • 偏好增长（概率 $p$）：以与当前连接强度 $A_{ij}$ 成正比的概率 $A_{ij}/S$ 选择连接进行增长。
    • 随机增长（概率 $1-p$）：随机选择一对神经元进行增长。

2. 活动无关模型的数学推导（连接强度的重尾性）

为了理解连接强度分布 $P(s)$ 的演化，作者使用了主方程法（Master Equation）。

概率变化分量推导：

在每个更新步中，$P(s)$ 的变化源于三个部分：

  1. 随机修剪：导致概率平均减少 $\frac{1}{n(n-1)}P_t(s)$。
  2. 偏好增长：
    • 强度从 $s-1$ 增加到 $s$ 的概率增量：$\frac{1}{n(n-1)}p(s-1)P_t(s-1)$。
    • 强度从 $s$ 增加到 $s+1$ 导致的概率减量：$-\frac{1}{n(n-1)}psP_t(s)$。
  3. 随机增长：
    • 概率增量：$\frac{1}{n(n-1)}\bar{s}(1-p)P_t(s-1)$。
    • 概率减量：$-\frac{1}{n(n-1)}\bar{s}(1-p)P_t(s)$。

稳态解与分布函数：

将上述项合并得到主方程： $P_{t+1}(s) - P_t(s) = \frac{1}{n(n-1)} [-P(s) + p((s-1)P(s-1) - sP(s)) + \bar{s}(1-p)(P(s-1) - P(s))]$

在稳态下（$P_{t+1} = P_t$），通过求解该递归关系，得到解析分布公式： $$P(s) \propto \frac{\Gamma [s + \bar{s}(\frac{1}{p}-1)]}{\Gamma [s + \bar{s}(\frac{1}{p}-1) + 1 + \frac{1}{p}]}$$

其中 $\Gamma$ 是欧拉伽马函数。在强连接极限（$s \gg \bar{s}/p$）下，该分布渐近服从幂律分布 $P(s) \approx s^{-\gamma}$，其幂律指数为： $$\gamma = 1 + \frac{1}{p}$$ 这证明了重尾特征仅取决于偏好增长在总增长中所占的比例 $p$。

3. 活动相关模型的数学推导（网络的聚类性）

为了引入赫布学习（Hebbian plasticity），模型引入了神经元活动。

神经元活动定义：

神经元的稳态活动 $x_i$ 由自洽方程定义： $$x = \tanh(\beta Ax)$$ 其中 $\beta$ 是相互作用强度（对应统计物理中的逆温度）。该系统等价于平均场伊辛模型。

协方差推导：

利用涨落-耗散定理（Fluctuation-dissipation Theorem），可以推导出神经元活动之间的协方差矩阵 $C$： $$C = \beta(I - \beta DA)^{-1}D$$ 其中 $D$ 是对角矩阵，$D_{ii} = 1 - x_i^2$。

弱相互作用下的级数展开：

在弱相互作用极限（$\beta \ll 1, x=0$）下，$D=I$，协方差可展开为： $$C = \beta(I + \beta A + \beta^2 A^2 + \beta^3 A^3 + \dots)$$

这一推导揭示了赫布学习如何通过协方差驱动网络自组织：

  1. 一阶项（$\beta A$）：协方差正比于现有连接强度。此时赫布增长等同于偏好增长，从而产生重尾分布。
  2. 二阶项（$\beta^2 A^2$）：协方差与共享邻居的神经元对相关（长度为2的路径）。赫布增长会强化这些对，从而形成三角形（聚类特征）。
  3. 高阶项：随着 $\beta$ 增加，赫布增长会闭合更长的环路。

该模型通过主方程法证明了简单的偏好增长机制足以产生幂律分布的连接强度，并通过统计物理的级数展开证明了活动依赖的赫布学习是网络聚类现象的物理根源。

  • 神经科学建模工具：为研究人员提供了一个极简且高效的工具，仅需极少参数即可预测或模拟大规模神经系统的结构分布，这对由于技术限制无法获得全量数据的研究具有重要参考价值。
  • 启发人工智能（AI）设计：由于该模型可直接映射到循环神经网络（RNN），研究结果可能启发开发更符合大脑生物特性的稀疏且具有重尾特征的人工神经网络，从而提升信息处理效率。
  • 疾病研究的潜在基础：连通性异常与多种神经系统疾病有关。该模型为理解可塑性机制失调如何导致网络结构病变（如连接异质性丧失）提供了理论基准。
  • 跨学科方法论参考：展示了如何利用统计物理工具解决生物学复杂系统问题，为生物物理学和网络科学的结合提供了范例。

[第1页，第4段] 神经元网络中的连接呈重尾（heavy-tailed）分布，少数神经元之间的连接强度远强于绝大多数神经元对。然而，这种重尾连接是否源于简单的底层机制尚不明确。本文提出一个突触自组织（synaptic self-organization）的最小模型：连接被随机修剪，突触强度在偏好性（preferential）与随机性（random）混合动力学下重新排列。在这些通用规则下，网络演化产生的连接强度分布渐近地呈现无标度（scale-free）特性，其幂律（power-law）指数仅取决于偏好性增长（而非随机增长）的概率。将模型扩展至包含神经元活动与Hebbian可塑性（Hebbian plasticity）后，我们发现网络中的聚类（clustering）也会自然涌现。我们在多种动物的连接组（connectome）中验证了这些预测，表明重尾与聚类连接可能源于网络自组织的通用原则，而非特定物种或系统的专属机制。

[第1页，第5段] 神经元通过复杂的突触连接网络进行通信与交互。尽管这一布线结构不断变化与重组[1-3]，但其远非随机——突触连接高度集中于少数神经元对[4]。事实上，连接强度分布呈重尾特征[5-9]，稀疏的强连接网络主导着弱相互作用的汪洋。这些强连接构成了神经元回路的骨干，支撑着从学习[11-13]、记忆[14-17]到感知[18-22]、通信[23,24]及运动控制[25-28]等无与伦比的信息处理能力。然而，尽管强连接在引导神经功能中至关重要，关于重尾连接如何在神经元群体中涌现仍存在根本性问题：它是否需要每个物种或神经系统特有的复杂生物物理过程？抑或重尾连接可以通用地从网络自组织原则中涌现？

[第1页，第6段] 重尾神经元连接
为回答这些问题，我们首先比较了多个物种的连接强度分布。收集足够数据以刻画连接强度分布的尾部特征是一项重大挑战，需要大体积神经组织的细胞级分辨率图谱[29]。然而，高通量电子显微镜与图像处理技术的近期进展，已能以前所未有的精度捕捉连接数千至数万个神经元的物理布线快照[5,11,12,18,19,25,26]。基于这些实验进展，现在已有可能探究大规模神经元连接的通用机制。

[第3页，第2段] 网络自组织模型

[第3页，第3段] 上述结果表明，重尾连接是神经元网络的一个普遍特征。因此，人们很自然地寻求一个同样普遍的解释。在复杂系统研究中，重尾分布通常源于优先连接（preferential attachment）或富者愈富（rich-get-richer）机制。然而，现有的网络模型侧重于度（degree）或节点强度（node strength）的分布\textsuperscript{33,34}，而这里我们研究的是连接强度。在突触连接（synaptic connectivity）的背景下，一种优先连接形式已经处于网络形成的核心：赫布可塑性（Hebbian plasticity），其中强连接的神经元更可能反映幂律（power law），其预测指数为 $\gamma = 1 + \frac{1}{p}$，c–d。连接异质性（c）和密度（d）作为 $p$ 的函数，通过数值模拟（数据点）和分析分布（线条）计算得出。连接密度是所有 $n(n-1)$ 个可能连接中非零强度连接的比例。e–i。来自方程（1）的分析模型预测，其中 $\bar{s} = 1$（以匹配面板b–d中的模拟），$p$ 拟合到果蝇中央脑（e）\textsuperscript{5}、果蝇视髓质（f）\textsuperscript{19}、秀丽隐杆线虫连接组（g）\textsuperscript{25,30}、沙蚕感觉运动回路（h）\textsuperscript{26}和小鼠视网膜（i）\textsuperscript{18}的连接分布（方法）。

[第3页，第4段] 为了回答这个问题，我们在此提出一个网络形成的最小模型，其中连接在优先和随机动态的混合作用下自组织。具体来说，我们从 $n$ 个神经元开始，它们由 $S$ 个连接强度单位连接（例如，每个单位可以代表一个突触、$1 \mu m^2$ 的接触面积，甚至非整数强度度量）。网络由连接矩阵 $A$ 定义，其中 $A_{ij}$ 是从神经元 $i$ 到神经元 $j$ 的有向连接强度，使得 $\sum_j A_{ij} = S$。在每个时间点，随机选择一个连接进行修剪，导致 $A_{ij} > 0$（图2a，左）。然后，每个修剪后的强度单位独立地重新分配给一对新的神经元（使得 $A_{ij} \rightarrow A_{ij} + 1$），方式有两种：（1）以概率 $p$，一个连接被优先选择用于增长，概率为 $A_{ij}/S$，与其当前强度成正比（图2a，顶部）；或（2）以概率 $1 - p$，随机选择一对神经元用于增长（图2a，底部）。这样，总连接强度 $S$ 保持不变，神经元之间的布线仅随时间重新排列。此外，我们注意到，在指定神经元数量后

[第4页，第1段] n 和总连接强度 $ S $，该模型仅包含一个参数 $ p $，表示优先增长（preferential growth）而非随机增长（random growth）的概率。

[第4页，第2段] 最终，我们希望理解上述动力学如何影响连接强度 $ s $ 的分布 $ P(s) $。利用主方程方法（master equation method）（此前已被用于研究度分布 $ ^{33} $），可以证明随着网络演化，连接强度趋近于一个解析稳态分布。

[第4页，第3段] $ P(s) \propto \frac{\Gamma \left[ s + \delta \left( \frac{1}{p} - 1 \right) \right]}{\Gamma \left[ s + \delta \left( \frac{1}{p} - 1 \right) + 1 + \frac{1}{p} \right]}, $

[第4页，第4段] 其中 $ \delta = \frac{s}{n(n-1)} $ 是平均连接强度，$ \Gamma(\cdot) $ 是欧拉伽马函数（Euler’s gamma function）（方法）。在本文中，我们将所有分布归一化到正连接强度 $ s > 0 $（即排除 $ s = 0 $ 的空连接）。在强连接极限 $ s \gg \delta/p $ 下，上述分布以幂律（power law）$ P(s) \approx s^{-\gamma} $ 衰减，其无标度指数（scale-free exponent）$ \gamma = 1 + \frac{1}{p} $ 仅取决于优先增长概率 $ P $（方法）。我们通过数值模拟（图 2b）确认了方程 (1) 中的解析分布和幂律尾部。

[第4页，第5段] 随着优先增长比例 $ p $ 减小，网络变得更加随机，从而限制了 $ P(s) $ 的重尾（heavy tail）并增加了指数 $ \gamma $（图 2b，左）。相反，如果优先增长占主导，强连接更可能变得更强，从而产生更重的尾部和更低的指数 $ \gamma $（图 2b，右）。为了量化幂律类分布的重尾性，常用度量是异质性（heterogeneity）$ \frac{1}{2} \langle |s - s’| \rangle \langle s \rangle $，其中 $ \langle \cdot \rangle $ 表示对 $ P(s) $ 的平均，$ \langle |s - s’| \rangle $ 是连接强度的平均绝对差 $ ^{37-39} $。虽然幂律分布的方差在 $ \gamma \leq 3 $（或我们模型中的 $ p \geq 0.5 $）时发散，但异质性（归一化到 0 和 1 之间）对所有 $ \gamma > 2 $（即所有 $ p < 1 $ 的值）都有良好定义。随着 $ p $ 增加，我们看到连接强度变得更加异质（图 2c），而连接密度下降（图 2d）。因此，优先动力学导致形成具有重尾连接强度的稀疏网络——这正是真实连接组（connectomes）中观察到的特征 $ ^{5,11,12,18,19,25,26,29} $。

[第4页，第6段] 我们甚至可以将优先概率 $ p $（模型中唯一的自由参数）拟合到单个连接组的连接分布；例如，果蝇（Drosophila）中央脑最好被描述为 60% 优先增长和 40% 随机增长的组合（图 2e）。事实上，尽管只拟合了一个参数，我们的简单模型对所有考虑的网络都提供了令人惊讶的良好描述（图 2e–i），优先增长比例从秀丽隐杆线虫（C. elegans）的 40%（图 2g）到果蝇视髓（optic medulla）（图 2f）和沙蚕（Platynereis）感觉运动回路（图 2h）的 100%。考虑到每个网络对网络结构都有不同的遗传约束，我们模型的成功更加令人惊讶。总之，这些结果表明，模型神经元可以在一个最小的“富者愈富”（rich-get-richer）机制下自组织，产生在真实连接组中观察到的稀疏、重尾网络。

[第4页，第7段] 引入神经元活动

[第4页，第8段] 上述模型即使不包含神经元活动的影响，也能生成具有现实连接强度的网络。然而，在真实的神经元网络中，突触连接不仅会自行演化，还会响应活动中的相关性——这一过程称为赫布可塑性（Hebbian plasticity）$ ^{2,31,35,36} $。通过包含这种网络结构与功能之间的反馈，我们将展示神经元连接组的其他属性会自然涌现。为了引入神经元之间的相关性，我们必须从神经元活动模型开始。虽然可以实现不同程度的生物真实性 $ ^{10,40} $，但为简单起见，这里我们考虑人工神经元，在每次网络更新之间，它们达到由自洽方程 $ x_i = \tanh \left( \beta \sum_j A_{ij} x_j \right) $ 定义的稳态活动 $ x_i $，其中 $ \beta \geq 0 $ 参数化相互作用强度，连接 $ A_{ij} $ 隐式地由 $ N $ 归一化（方法）。该模型是伊辛模型（Ising model）的平均场近似（mean-field approximation）$ ^{41-43} $，已被证明能捕捉神经元群体的关键特征 $ ^{44,45} $。此外，活动 $ x_i $ 可以直接映射到发放率（firing rates）（方法），使模型等效于人工递归神经网络（recurrent neural network）$ ^{10,43,46} $。该模型的主要优势在于，如果连接 $ A_{ij} $ 是对称的（如下文假设），那么我们可以利用涨落-耗散定理（fluctuation–dissipation theorem）推导出协方差（covariances）的简洁解析形式（方法）：$ C = \beta (I - \beta DA)^{-1} D $，其中 $ D_{ij} = (1 - x_i^2) \delta_{ij} $ 是对角矩阵，$ I $ 是单位矩阵。

[第4页，第9段] 我们现在准备将网络动力学扩展到包含活动依赖性可塑性（activity-dependent plasticity）。随机修剪（random pruning）（图 2a，左）和随机增长（图 2a，下）保持不变，但我们将优先增长替换为赫布增长（Hebbian growth）：不是以与当前强度 $ A_{ij} $ 成比例的概率选择连接（图 2a，上），而是以与协方差 $ C_{ij} $ 成比例的概率选择一对神经元（方法）。为了直观理解这个活动依赖性模型，我们注意到在弱相互作用极限 $ \beta \ll 1 $ 下，$ x_i = 0 $，产生协方差

[第4页，第10段] $ C = \beta \left( \beta A + \beta^2 A^2 + \beta^3 A^3 + \cdots \right) = \beta \sum_{n=1}^{\infty} \left( \beta A \right)^n \quad \text{对于} \quad i \neq j. $

[第4页，第11段] 在 $ \beta $ 的最低阶，协方差与连接强度成正比 $ C \propto A $，因此赫布可塑性强化了现有连接；也就是说，赫布增长的作用恰好等同于原始模型中的优先增长（图 3a，上）。因此，原始的活动无关动力学（图 2）正是更一般的活动依赖性模型的弱相互作用极限。

[第4页，第12段] 在 $ \beta $ 的次低阶，相关性正比于 $ A^2 $，因此赫布可塑性连接网络中共享共同邻居的神经元（即通过长度为二的路径相互作用的神经元）。在这种情况下，活动依赖性增长导致三角形（triangles）的形成（图 3a，中），正如我们将看到的，这会在连接拓扑中产生聚类（clustering）。一般来说，随着相互作用强度 $ \beta $ 增加到接近 1（随机网络的临界相互作用强度；补充信息第 3 节），赫布可塑性会强化越来越大的拓扑距离上的相互作用，从而在网络中产生越来越长的环路（图 3a，下）。重要的是，我们预期这些结果（以及下面的结果）会定性推广到其他神经元活动模型。只要神经元之间的相关性随网络中的拓扑距离减小——即对于任何神经元活动模型，直接连接产生最强相关性，长度为二的连接产生较弱相关性，依此类推——我们的赫布可塑性模型仍会强化现有连接（一阶），随后是网络中逐渐变长的环路（图 3a）。

[第7页，第2段] 讨论 在多种不同物种中，神经元连接强度均呈现相似的重尾分布（图1），这表明存在共同的潜在机制。然而，通过简单规则生成具有真实特征的神经元连接是众所周知的难题\textsuperscript{50,51}。在此，我们开发了一个最小模型（minimal model），其中突触连接在优先增长（preferential growth）和随机动力学（random dynamics）的混合作用下自组织。由此产生的网络展现出渐近无标度（scale-free）的连接强度分布，其指数 $\gamma = 1 + \frac{1}{p}$ 仅取决于优先增长的比例 $p$（图2）。此外，通过将模型推广至包含Hebbian（活动依赖）可塑性，网络动力学自然产生了聚类现象（图3），这是神经元连接的另一个显著特征（图4）。

[第7页，第3段] 鉴于该模型的简洁性，未来工作可以立即开始纳入更真实的可塑性机制，这进而可能产生在神经元连接组（connectomes）中观察到的其他特性。例如，可以基于等时相关性（equal-time correlations）更新突触连接，而是进一步推广活动依赖模型以包含脉冲时间依赖可塑性（spike-time-dependent plasticity），其中突触基于时间延迟相关性（time-delayed correlations）进行更新\textsuperscript{2,35}。这些时间不对称性将自然产生连接本身的不对称性，这是真实连接组的一个核心属性\textsuperscript{4–9,11,12,18,19,25,26,47}。此外，为简化起见，我们的网络动力学（1）包含了关于总连接强度 $S$ 的全局信息，（2）假设修剪任何给定连接的概率是均匀的（图2a左），并且（3）允许神经元之间的所有可能连接。未来工作可以通过限制为网络拓扑的局部信息、考虑非均匀修剪以及约束允许的连接——这是真实神经元可塑性的三个特征\textsuperscript{52,53}——来引入额外的生物学真实性。

[第7页，第4段] 除了新的可塑性机制，还可以在活动依赖模型中直接实现更具生物物理真实性的神经元活动模型\textsuperscript{40}。在此，为了便于解析推导，我们专注于一个递归非线性动力学（recurrent nonlinear dynamics）的统计物理模型。像这样的Ising模型（Ising models）能够再现真实神经元群体中观察到的发放率（firing rates）和相关性（correlations）\textsuperscript{44,45}。这些最大熵模型（maximum entropy models）主要应用于静态网络拓扑，为动态连接性的研究打开了大门。或者，在未来工作中，可以研究更具生物学启发性的脉冲活动（spiking activity）或神经振荡（neural oscillations）模型\textsuperscript{10,54}。重要的是，对于任何神经元间相关性随网络距离减小的模型，我们的框架仍应能产生同时具有重尾连接强度分布和高聚类系数的网络（图3）。这些结果共同展示了连接组的两个基本特征——重尾连接性和聚类——如何从简单的网络动力学中产生，为未来研究神经元连接的自组织提供了框架。

[第9页，第2段] 神经元连接数据

[第9页，第3段] 本文分析的数据集均先前已发表并可公开访问\cite{5,18,19,25,26,32}。所有连接组（connectome）均通过电子显微镜（electron microscopy）在神经元层面进行切片和成像\cite{5,18,19,25,26}。随后，使用手动标记和自动化图像处理相结合的方法追踪神经元和突触（synapse）（或小鼠视网膜中的接触点）。关于果蝇中央脑（图1a,b）\cite{5}、果蝇视髓质（图1c）\cite{19}、秀丽隐杆线虫（图1d）\cite{25,30}、沙蚕感觉运动回路（图1e）\cite{26}和小鼠视网膜（图1f,g）\cite{18}的进一步实验细节，请参见相应参考文献。我们已将神经元及其连接列表以通用格式公开提供（‘数据可用性’）。

[第9页，第4段] 在与活动无关模型（activity-independent model）（图1和2）进行比较时，连接$A_{ij}$是有向的，反映了从一个神经元$i$到另一个神经元$j$的突触数量（或对于小鼠视网膜，为接触面积）。对于小鼠视网膜，我们将每个连接的总面积四舍五入到最接近的$\mu m^2$，以创建连接强度的离散单位。在与活动依赖模型（activity-dependent model）（图4）进行比较时，我们使用连接组的对称化版本，其中连接$A + A^I$反映了两个方向上神经元之间的突触数量（或接触面积）。在表1中，我们列出了不同连接组的有向和对称化版本的网络属性。

[第9页，第5段] 为了研究神经元活动的协方差（covariance）（图1h和补充图1），我们研究了一个先前发表的数据集，该数据集包含清醒小鼠视觉皮层中大型神经元群体的双光子钙成像记录\cite{32}。为了解释神经元之间荧光强度的变化，我们对预处理后的活动迹线进行二值化，以反映在每个时间点神经元是高于还是低于其平均活动。关于实验设置和数据处理的更多细节，请参见参考文献32。

[第9页，第6段] 模拟活动无关模型

[第9页，第7段] 在活动无关模型（图2）中，我们从$n$个神经元、$S = \sum_{ij} A_{ij}$个连接强度单位（平均连接强度为$s = \frac{S}{n(n-1)}$）和优先增长概率$p$开始。然后，网络按照正文中的描述进行演化。在整篇论文中，我们模拟具有$n = 10^3$个神经元的网络，总共有$n(n-1) \approx 10^6$个可能的有向连接，并且（除非另有说明）平均连接强度为$s = 1$。我们通过将强度$S$随机分配到可能的连接中来初始化每个网络。在计算分布（如图2b）或感兴趣的量（如图2c,d）时，我们取100个网络样本；在每个样本之间，我们修剪$n(n-1)$个不同的连接，使得每个有向神经元对平均被修剪一次。在采集任何样本之前，我们还会对每个连接平均修剪50次以进行预烧（burn-in）。在实践中，为了加快计算速度，可以并行运行多个网络更新；这里我们一次修剪1%的可能连接，并同时重新分配所有被修剪的强度。我们确认这种并行化不会影响模拟的准确性（图2b）。在图3和4中，为了与活动依赖模型进行比较，我们研究对称网络（而不是有向网络）。在实践中，模拟的唯一区别在于有$n(n-1)/2$个可能的连接（神经元对）而不是$n(n-1)$个有向对，因此总突触强度由$S = \frac{1}{2} \sum_{ij} A_{ij}$给出。模拟活动无关模型的代码已公开提供（‘代码可用性’）。

[第9页，第8段] 推导连接强度分布

[第9页，第9段] 当网络根据活动无关动力学演化时，连接强度收敛到方程(1)中定义的稳态分布$P(s)$。为了推导$P(s)$，我们首先写出主方程（master equation），描述从动力学的一个时间步$t$到下一步的连接强度分布变化$P_{t+1}(s) - P_t(s)$。在每次网络更新期间，一个随机连接被修剪，导致概率平均减少$-\frac{1}{n(n-1)} P_t(s)$。平均而言，修剪移除了$s$个连接强度单位。对于每个被修剪的强度单位，我们以概率$p$执行优先增长（preferential growth），以概率$S$选择每个强度为$s$的连接。平均而言，这种优先增长导致概率增加$sp \frac{s-1}{s} P_t(s-1) = \frac{1}{n(n-1)} p(s-1) P_t(s-1)$和减少$-sp \frac{s}{s} P_t(s) = -\frac{1}{n(n-1)} psP_t(s)$。最后，对于每个被修剪的强度单位，我们以概率$1-p$执行随机增长（random growth），平均导致概率增加$\frac{1}{n(n-1)} s(1-p) P_t(s-1)$和减少$-\frac{1}{n(n-1)} s(1-p) P_t(s)$。

[第9页，第10段] 结合上述贡献，我们得到以下主方程，

[第9页，第11段] $$P_{t+1}(s) - P_t(s) = \frac{1}{n(n-1)} [-P_t(s) + p((s-1)P_t(s-1) - sp(s)) + s(1-p)(P_t(s-1) - P_t(s))]$$ \hspace{1cm} (3)

[第9页，第12段] 随着网络的演化，连接强度趋近于稳态分布$P_{t+1}(s) = P_t(s) = P(s)$，这将方程(3)转化为以下递归关系：

[第9页，第13段] $$P(s) = \frac{p(s-1) + s(1-p)}{1 + ps + s(1-p)} P(s-1).$$ \hspace{1cm} (4)

[第9页，第14段] 求解$P(s)$，我们得到方程(1)中的分布，我们注意到在整篇论文中，该分布被归一化以覆盖正连接强度$s > 0$（即排除强度为零的连接）。在强连接极限$s \gg s/p$下，我们有近似

[第9页，第15段] $$\Gamma \left[ s + s \left( \frac{1}{p} - 1 \right) \right] \approx \Gamma(s) s^{\left( \frac{1}{p} - 1 \right)} \text{ 和 } \Gamma \left[ s + s \left( \frac{1}{p} - 1 \right) + 1 + \frac{1}{p} \right] \approx \Gamma(s) s^{\left( \frac{1}{p} - 1 \right) + 1 + \frac{1}{p}}.$$

[第9页，第16段] 因此，分布$P(s)$渐近地按$s^\gamma$缩放，其中$\gamma = 1 + \frac{1}{p}$。方程(1)中的解析稳态分布和幂律尾部（power-law tail）在图2b中得到数值确认。为了计算最能描述给定连接组的优先概率$p$（如图2e–i所示），我们在对数概率的均方根误差上运行梯度下降（gradient descent）（使用方程(1)中的解析分布）。

[第9页，第17段] 神经元活动中的协方差

[第9页，第18段] 为了研究活动依赖可塑性（activity-dependent plasticity），我们实现了模型神经元，这些神经元在每次网络更新之间达到由非线性方程$x = \tanh[\beta(Ax + b)]$定义的稳态活动$x_i$，其中$\beta$是相互作用强度，$b$是偏置（这里假设为零以简化），并且$\tanh(\cdot)$是逐分量应用的。此外，如常见做法，我们隐式地将连接$A_{ij}$除以$ns$进行归一化，使得对于大型网络，每个神经元的总相互作用强度趋近于一。该系统等价于一个平均场伊辛模型（mean-field Ising model），具有逆温度$\beta$、相互作用$A_{ij}$和外场$b_i = 0$。此外，我们可以将该模型映射到一个等价系统$\tilde{x} = \sigma[\beta(\tilde{A}\tilde{x} + \tilde{b})]$，其中状态$\tilde{x}i = (x_i + 1)/2 \in [0, 1]$代表发放率，$\sigma(\cdot)$是逻辑函数（logistic function），新参数由$\tilde{A}{ij} = 4A_{ij}$和$\tilde{b}i = 2(b_i - \sum_j A{ij})$给出。

[第9页，第19段] 对于对称连接$A = A^T$，可以使用涨落-耗散定理（fluctuation–dissipation theorem）计算活动中的协方差，

[第9页，第20段] $$C_{ij} = \frac{dx_i}{db_j} = \beta \text{sech} \left[ \beta \left( \sum_k A_{ik} x_k + b_i \right) \right]^2 \left( \sum_k A_{ik} \frac{dx_k}{db_j} + \delta_{ij} \right)$$ \hspace{1cm} (5)

[第9页，第21段] $$= \beta(1 - x_i^2) \left( \sum_k A_{ik} C_{kj} + \delta_{ij} \right)$$

[第9页，第22段] 给定网络活动的稳定解$x$，可以求解协方差$C = \beta(I - \beta DA)^{-1}D$，其中$D_{ij} = (1 - x_i^2)\delta_{ij}$，$I$是单位矩阵。

[第9页，第23段] 上述协方差表达式适用于任意相互作用强度$\beta$和偏置$b$。然而，对于零偏置$b = 0$，情况有所不同。

[第10页，第1段] 进一步简化：当相互作用足够弱时，即 $\beta < \rho(A)$，其中 $\rho(\cdot)$ 为谱半径（即最大特征值的模长），自洽方程的唯一解为 $x = 0$。此时有 $D = I$，从而得到弱相互作用展开式。

[第10页，第2段] $$C = \beta(I - \beta A)^{-1} = \beta \sum_{n=0}^{\infty} (\beta A)^n = \beta (I + \beta A + \beta^2 A^2 + \ldots). \tag{6}$$

[第10页，第3段] 当相互作用强度 $\beta$ 趋近于 $\rho(A)$ 时，解 $x = 0$ 变得不稳定，且方程(6)中的协方差发散；在此意义上，$\rho(A)$ 定义了临界相互作用强度。例如，若连接强度 $S$ 随机分布，则可证明在极限 $n \to \infty$ 下 $\rho(A) = 1$（补充信息第3节）。因此，对于随机连接性，弱相互作用展开对所有 $\beta < 1$ 均成立。

[第10页，第4段] 模拟活动依赖性模型

[第10页，第5段] 在活动依赖模型中，网络演化过程与活动独立模型（对称连接）完全相同，唯有一个关键差异：在优先生长阶段，我们不再以连接强度$A_{ij}$成比例的概率选择连接，而是以神经元对协方差$C_{ij}$成比例的概率选择神经元对。我们将这一新规则称为赫布生长（Hebbian growth）或赫布可塑性（Hebbian plasticity）。在每次动力学迭代前，需按前述方法计算协方差矩阵$C$，这进一步要求求解神经元平均活动的解$x$。通过初始化$x = -1$并迭代非线性方程$x \leftarrow \tanh(\beta Ax)$直至收敛，可高效完成计算。仿真中，我们考虑包含$n = 10^3$个神经元的网络，共有$n(n-1)/2 \approx 5 \times 10^5$条可能的无向连接，平均连接强度$S = 1$（除非另有说明）。与活动独立模型相同，每次计算记录100个样本，样本间每条可能连接平均被修剪一次，样本前每条可能连接经50次修剪作为预烧期（burn-in）。在图3c–f的相图（phase diagram）中，为改善$p \geq 0.7$时的采样效果，每个数据点取十次仿真的平均值。活动依赖模型的仿真代码已公开（代码可用性，Code Availability）。
