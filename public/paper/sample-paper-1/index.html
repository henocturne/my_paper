翻译

[第1页，第1段] 动力学相变（Dynamical phase transitions, DPTs）是一种揭示随时间涌现的临界行为的临界现象，代表了非平衡物理（nonequilibrium physics）的新前沿[1–10]。与传统相变（通常由温度或压力等外部参数驱动）不同，DPTs发生在临界时间$t_c$处，此时物理可观测量呈现非解析行为。尽管这些相变已在量子系统中得到广泛研究，但其在经典背景下的作用仍 largely 未被充分探索，仅有来自非平衡弛豫至平衡态的均场分析（mean-field analyses）[11,12]和模拟[13]的有限进展。

[第1页，第2段] 引人注目的是，近期关于宏观复杂系统（包括生态崩溃（ecological collapse）[14,15]、金融危机（financial crises）[16,17]和电网故障（power grid failures）[18]）的实验报告了有限时间内的突变动力学变化。这些事件虽未被正式归类为DPTs，但具有突变性集体变化等关键特征。这些现象与量子DPTs之间的显著相似性表明，临界时间动力学（critical temporal dynamics）可能是复杂系统的普遍特征。这引发了关于其更广泛关联性和潜在普适性的有趣问题。

[第1页，第3段] 更近期，关于社交网络（social networks）的研究为经典背景下DPTs的涌现提供了令人信服的证据[19–22]。这些实验揭示，某些物理可观测量$z(t)$在临界时间$t_c$处根据普适双曲标度（universal hyperbolic scaling）发散：

[第1页，第4段] $$z(t) \sim (t_c - t)^{-1}.$$ (1)

[第1页，第5段] 与量子DPTs（其中非解析性出现但不发散）不同，这种经典双曲标度揭示了时间临界性（temporal criticality）的独特特征，且似乎在不同领域普遍存在。例如，经济学中观察到的双曲贴现（hyperbolic discounting）[23–26]（可合理化拖延行为和截止日期效应）也遵循这一标度，正如截止日期前学术投稿激增所证实[27]。尽管其普遍存在，但该普适性的理论基础仍知之甚少。

[第1页，第6段] 现有的非平衡经典相变理论框架大致分为两类。第一类处理在时变控制参数（类似于平衡相变）下涌现的不同相[21,28–31]。第二类包含自组织临界性（self-organized criticality）模型[32–36]，其中临界点出现在渐近极限$t \to \infty$而非有限$t_c$处。这两类均未完全捕捉DPTs特征性的有限时间奇异性（finite-time singularities），表明需要新的理论方法。

[第1页，第7段] 在本快报（Letter）中，我们引入了一个预测非平衡网络中DPTs涌现的理论框架。我们的核心见解是：非线性相互作用（nonlinear interactions）起着关键作用。类比多体物理学（many-body physics），无相互作用的随机图（random graph）类似于无DPTs的非相互作用粒子系统。然而，一旦引入非线性相互作用，系统的集体动力学（collective dynamics）将发生根本性改变。为证明这一点，我们考虑一个涉及二次相互作用（quadratic interactions）的简单模型，其动机源于三角形闭合（triangle closure），一种

[第2页，第1段] 在社交网络中，这是一种普遍存在的机制（ubiquitous mechanism）。在该模型中，边之间的二次相互作用（quadratic interactions）自然产生了动态相变（DPTs）。值得注意的是，该模型可以解析求解，重现了公式(1)中表达的普适标度行为（universal scaling behavior）。此外，我们证明了关键的网络特征，如度分布（degree distribution）和聚类系数（clustering coefficient），在接近 $t_c$ 时表现出临界标度行为（critical scaling behavior）。这些结果为理解经典系统中的非平衡临界性（nonequilibrium criticality）奠定了理论基础，并揭示了与量子动态相变（quantum DPTs）的相似之处。

[第2页，第2段] 理论框架（Theoretical framework）——我们考虑一个由 $N$ 个顶点组成的有向网络（directed network），该网络经历随机的边添加和移除。具体来说，顶点 $i$ 以概率速率 $\alpha/N$ 连接到顶点 $j$ 以形成一条新边，而边以速率 $\gamma$ 被移除。参数 $\alpha$ 和 $\gamma$ 分别表征边形成和移除的速率，因子 $1/N$ 确保了网络的稀疏性（sparsity）。期望平均度（expected average degree）$\bar{z}(t) = (1/N) \left\langle \sum_{ij} A_{ij} \right\rangle$ 的演化，其中 $\left\langle \ldots \right\rangle = \int \ldots P(A, t) dA$，遵循线性微分方程，

[第2页，第3段] $$\frac{dz}{dt} = \alpha - \gamma z,$$

[第2页，第4段] 其稳态解（stationary solution）为 $z(t \to \infty) = \alpha/\gamma$。在这种非相互作用（noninteracting）的情况下，网络仍然是一个随机图（random graph），不表现出动态相变。

[第2页，第5段] 接下来我们将证明，动态相变的出现需要非线性相互作用（nonlinear interactions）。一种自然的方法是将边添加速率修改为 $\alpha/N + U_{\text{int}}$，其中 $U_{\text{int}}(A)$ 表示一个依赖于布尔邻接矩阵（Boolean adjacency matrix）$A$ 的相互作用项。虽然边移除速率也可以类似地修改，但为了简单起见，我们保持该参数不变。相互作用项可以展开为 $U_{\text{int}}(A) = \beta_0 A + \beta A^2 + O(A^3)$。为了隔离非线性效应，我们忽略线性项，只保留主要的非线性贡献，得到 $U_{\text{int}}(A) \approx \beta A^2$，其中 $\beta$ 是耦合常数（coupling constant）。这些相互作用自然地被解释为一种三元闭包机制（triadic closure mechanism）[37]：共享一个共同邻居的两个顶点 $i$ 和 $j$ 更有可能形成直接连接。这以一个与 $\sum_k A_{ik} A_{kj} = (A^2)_{ij}$ 成正比的额外速率发生，导致以下网络动力学：

[第2页，第6段] $$W[A_{ij}(0 \to 1)] = \left(\frac{\alpha}{N} + \beta (A^2)_{ij}\right), \tag{2a}$$

[第2页，第7段] $$W[A_{ij}(1 \to 0)] = \gamma. \tag{2b}$$

[第2页，第8段] 虽然三元闭包通常与社交网络相关，但我们的理论将其视为主要的非线性相互作用，将其适用性扩展到社交背景之外。

[第2页，第9段] 在弱相互作用（weak-interaction）区域（$\beta$ 较小），网络表现为一个没有动态相变的随机图。然而，随着 $\beta$ 增加，非线性相互作用显著改变了动力学，导致边聚类（edge clustering）和有限时间奇异性（finite-time singularities）。图1展示了所提出模型在 $\beta = 0.5$ 和 $\alpha = \gamma = 1$ 时网络的时间演化，这表明存在一个临界时间 $t_c$，在该时间网络结构发生显著变化。

[第2页，第10段] 为了量化这种快速变化，我们推导了任意连通子图（connected subgraphs）密度 $\rho(G)$ 的时间演化，该密度在稀疏性条件下由施温格-戴森方程（Schwinger-Dyson equations, SD equations）给出（参见补充材料 [38]，第1.1节）。对于最简单的子图，即两个顶点之间的连接（link），其密度对应于平均度 $z$，遵循

[第2页，第11段] $$\frac{dz}{dt} = \alpha - \gamma z + \beta (z^2 - \Delta), \tag{3}$$

[第2页，第12段] 其中 $\Delta = (1/N) \left\langle \sum_{ijk} A_{ij} A_{jk} A_{ik} \right\rangle$ 衡量网络中的三角形密度（triangle density）。动力学项 $\alpha - \gamma z$ 与非相互作用的随机图模型相同，而相互作用项 $\beta (z^2 - \Delta)$ 引入了一个放大聚类的反馈回路（feedback loop）。

[第2页，第13段] 这个微分方程不是封闭的，因为 $\Delta$ 依赖于四顶点矩形形状（four-vertex rectangular shapes）的数量。而这些四顶点矩形形状又依赖于五顶点形状的数量，依此类推。这种层级结构创建了一个无限方程塔，这是施温格-戴森方程的一个标志性特征。例如，

[第2页，第14段] $$\frac{d\Delta}{dt} = \beta (z^2 - \Delta) - 3\gamma \Delta + O(\beta^3), \tag{4}$$

[第2页，第15段] 其中 $O(\beta^3)$ 表示更高阶的项，例如四顶点形状。对施温格-戴森方程应用标准的微扰截断方案（perturbative truncation scheme），并注意到 $\Delta \sim O(\beta)$，我们可以在公式(3)中忽略它，得到

[第2页，第16段] $$z(t) \sim \begin{cases} \text{常数} & (\beta \leq \frac{\gamma^2}{4\alpha}, t \to \infty), \ 1/(t - t_c) & (\beta > \frac{\gamma^2}{4\alpha}, t \to t_c), \end{cases} \tag{5}$$

[第3页，第1段] 其中临界时间 ( t_c ) 由 ( t_c = \omega^{-1}[\text{acot}(2\omega) + (\pi/2)] ) 给出，且 ( \omega = \sqrt{\alpha\beta - (\gamma^2/4)} )。因此，( t_c ) 仅通过 ( \omega ) 依赖于 ( (\alpha, \beta, \gamma) )，且有限时间奇异性仅出现在超临界区域（supercritical regime）( \beta > \gamma^2/(4\alpha) )（参见补充材料[38]第1.1节）。此外，方程(5)识别出两个不同的相：在“平衡相”（equilibrium phase）中，当 ( \beta \leq (\gamma^2/4\alpha) ) 时，( z(t) ) 在 ( t \to \infty ) 时趋近于常数，表明网络收敛到稳态（stationary state）。在“非平衡相”（nonequilibrium phase）中，当 ( \beta > (\gamma^2/4\alpha) ) 时，模型预测了一个动态相变（DPT, dynamical phase transition），其中 ( z(t) ) 在 ( t \to t_c ) 时呈双曲线发散（hyperbolically diverge），与方程(1)中的经验定律一致。重要的是，除平均度（average degree）之外的可观测量以不同指数发散，反映了它们的结构序（structural order）。例如，三角形密度（triangle density）标度为 ( \Delta \sim z^2 \sim [1/(t_c - t)^2] )，捕捉了其次近邻（second-neighbor）性质。更一般地，高阶子图密度（higher-order subgraph densities）以 ( z ) 的幂次发散，其指数由有效邻域阶数（effective neighborhood order）决定。

[第3页，第2段] 上述推导代表了施温格-戴森方程（Schwinger-Dyson equation）无穷级数的一个特例，该方程将邻接矩阵（adjacency matrix）( A(t) ) 视为量子场论中的场变量，并忽略了高阶项 ( \square \sim O(\beta^3) )（参见补充材料[38]第1.1节）。注意，添加高阶项不会改变上述物理图像，但会引入对耦合常数（coupling constant）的修正。例如，考虑方程(4)中 ( \Delta ) 的贡献，同时忽略 ( O(\beta^3) ) 项并应用绝热近似（adiabatic approximation），得到修正 ( \beta \to \beta’ := (3\beta\gamma/3\gamma + \beta) = \beta - \beta^2/(3\gamma) + O(\beta^3) )。这可以解释为由高阶修正产生的重整化耦合常数（dressed coupling constant）。将方程(5)中的 ( \beta ) 替换为重整化值 ( \beta’ )，可提供对 ( z(t) ) 的精确预测，如图2(a)所示。尽管绝热近似在快速变化（尤其是 ( t \to t_c ) 时）预期会失效，但我们发现即使这种简单近似也与平衡相和非平衡相的数值模拟结果吻合得非常好。上述理论分析可总结为以 ( \alpha/\gamma ) 和 ( \beta/\gamma ) 表示的相图（phase diagram），其中相边界（phase boundary）( \beta’(\beta)/\gamma = (4\alpha/\gamma)^{-1} ) 将平衡相与非平衡相分开。图3(a)将我们的理论预测与数值模拟进行了比较，其中虚线表示树图水平（tree level）的理论预测 ( (\beta’ = \beta) )，实线则包含了三角形修正（triangle correction）( (\beta’ = (3\beta\gamma/3\gamma + \beta)) )。我们发现，两种预测在小 ( \beta ) 值时均与数值结果吻合良好，而三角形修正即使在相对较大的 ( \beta ) 值时也与数值结果一致。

[第3页，第3段] 令人惊讶的是，我们的理论表明，即使很小的 ( \beta ) 值也能导致非平衡相，前提是动力学速率（kinetic rate）( \alpha ) 足够大。这意味着，向随机图模型（random graph model）引入任意小的非线性相互作用（nonlinear interactions）都可能从根本上改变底层网络演化的性质，从而潜在地导致动态相变。

[第3页，第4段] 图2. 理论预测与数值模拟的比较：(a) 平均度 ( z(t) ) 和 (b) 序参量（order parameter）( q(t) )，参数为 ( \alpha = 1 )，( \gamma = 1 )，( \beta = 1/4 )（绿色）和 ( \beta = 1/2 )（红色）。实线表示理论预测，散点对应 ( N = 2000 ) 的模拟结果。对于 ( \beta = 1/4 )（绿色），平均度 ( z(t) ) 收敛，而序参量 ( q(t) ) 消失，表明处于平衡相。对于 ( \beta = 1/2 )（红色），( z(t) ) 呈现双曲线标度（hyperbolic scaling）并在有限临界时间 ( t_c \approx 5.9 ) 处发散。相应地，( q(t) ) 在 ( t_c ) 处出现尖锐跳跃，标志着从稀疏网络到密集网络的一阶动态相变（first-order DPT）。

[第3页，第5段] 一级相变（First-order phase transition）——为进一步表征非平衡相，我们定义序参量 ( q = \lim_{N \to \infty} z/N )，表示边数相对于完全图（complete graph）的比例。根据定义，( 0 \leq q \leq 1 )。在稀疏图（sparse graph）区域 ( [z \sim O(1)] ) 中，有 ( q = 0 )，这在平衡相以及非平衡相临界时间之前 ( t < t_c ) 均成立。然而，对于

[第3页，第6段] 图3. (a) 模型在 ( \alpha-\beta ) 参数空间中的相图，显示两个不同的相：平衡相和非平衡相（灰色区域）。曲线表示理论预测，散点对应相边界的模拟结果。(b) 相图展示了从稀疏图相到密集图相（dense graph phases）的转变。彩色表面量化了相边界。此处，( \alpha )、( \beta ) 和 ( t ) 均通过 ( \gamma ) 进行重标度（rescaled）以使其无量纲化。

[第4页，第1段] 当 ( t > t_c ) 时，网络变得稠密，导致 ( q > 0 )。这种稀疏-稠密网络相变已在理论模型和现实世界系统中被观察到，包括网络致密化（network densification）[39] 和团簇渗流（clique percolation）[40]。这些系统共享类似于三角闭合（triangle closure）的聚类机制，当聚类强度超过临界阈值时，稀疏性会崩溃。然而，传统模型展现的相变由外部参数控制。相比之下，在我们的模型中，这种相变由有限临界时间决定，标志着它属于动态相变（DPT）。方程 (5) 中 ( t = t_c ) 处的奇异性表明这是一级相变（first-order phase transition），其特征是 ( q(t = t_c) ) 从零到非零值的间断性（即潜热，latent heat）。这一行为如图 2(b) 所示。

[第4页，第2段] 方程 (4) 中的解析结果仅在 ( (t < t_c) ) 时有效，因为稀疏条件在临界时间后失效。为了确定 ( t > t_c ) 时的 ( q(t) )，我们需要更好地理解所观察到的 DPT。对于足够大的耦合，网络初始为稀疏状态，动力学项（kinetic terms）主导演化。随着连接增长，由三角闭合驱动的非线性相互作用（nonlinear interactions）变得日益显著，从而在动力学项与非线性相互作用之间形成竞争。一旦非线性相互作用占据主导地位，边形成过程将发生快速级联，导致 DPT。

[第4页，第3段] DPT 发生后，网络凝聚成一个紧密连接的核心，形成完全图（complete graph），同时伴随少量度为零的孤立顶点（isolated vertices）。假设孤立顶点占比为 ( p )，则完全图核心的占比为 ( [1 - p(t)]N )，因此 ( q(t) = [1 - p(t)]^2 )。一旦孤立顶点与核心建立单条边，由于共同邻居数量为 ( O(N) )（发散量），它将立即连接到核心中的所有其他顶点。因此，孤立顶点连接到核心中顶点的速率会增大。这意味着 ( p(t) = p_0 e^{-\alpha(t-t_c)} ) 因随机连接到核心而呈指数衰减，其中 ( p_0 ) 是 ( t = t_c ) 时孤立顶点的占比。由此我们得到

[第4页，第4段] [ q(t) = \left( 1 - p_0 e^{-\alpha(t-t_c)} \right)^2, ]

[第4页，第5段] (6)

[第4页，第6段] 适用于 ( t \geq t_c )。该预测与数值模拟结果高度吻合 [图 2(b)]。潜热 ( q(t_c) = (1 - p_0)^2 ) 与临界孤立顶点占比 ( p_0 ) 相关，我们将在后文讨论。

[第4页，第7段] 总之，对于平衡相（equilibrium phase），网络在任何 ( t ) 下都将保持稀疏。对于非平衡相（nonequilibrium phase），临界时间 ( t_c ) 进一步将状态区分为稀疏网络 ( (t < t_c) ) 和稠密网络 ( (t > t_c) )。临界时间 ( t_c ) 取决于 ( \alpha )、( \beta ) 和 ( \gamma )，其中相对较大的 ( \beta ) 对应较小的 ( t_c )，即系统更早达到临界时间。图 3(b) 在三维相图中展示了这些发现。彩色相边界曲面将稀疏网络与稠密网络对应的区域分隔开。

[第4页，第8段] 临界行为（Critical behavior）——为研究 DPT 附近的临界行为，我们特别关注度分布（degree distribution）。对于非相互作用模型（( \beta = 0 )），度遵循泊松分布（Poisson distribution）。对于有限非线性耦合，在树级近似（tree level）下，我们发现含时度分布 ( P(k, t) ) 满足

[第4页，第9段] [ \frac{\partial}{\partial t} P(k, t) = [\alpha + \beta(k - 1)z(t)]P(k - 1, t) - [\alpha + \beta k z(t) + \gamma k]P(k, t) + \gamma (k + 1)P(k + 1, t). ]

[第4页，第10段] (7)

[第4页，第11段] 该方程可通过生成函数法（generating function method）解析求解（参见补充材料 [38] 第 1.2 节）。对于非平衡相，当系统接近临界时间 ( t_c ) 时，度分布呈现幂律形式（power-law form），如图 4(a) 和 4(b) 中理论预测与数值模拟结果所示。最终，( P(k, t \to t_c) \sim k^{-\gamma} ) 形成无标度网络（scale-free network）[41,42]，其指数 ( \gamma = 1 )，表明平均度 ( z ) 发散，这是 DPT 的信号。这一点尤其有趣，因为我们并未使用优先连接（preferential attachment）等机制来生成无标度性 [41,42]。相反，DPT 附近的临界行为自动产生了无标度性，这超越了传统无标度网络的范式。

[第4页，第12段] 此外，尽管树级近似仅适用于 ( t \leq t_c )，但该解析结果使我们能够计算孤立顶点占比 ( p_0 = P(0, t_c) )（参见补充材料 [38] 第 1.2 节）。图 4(c) 显示了在固定 ( \alpha = \gamma = 1 ) 时，不同耦合常数 ( \beta ) 下的孤立顶点占比 ( p_0 )。结果表明，更强的非线性相互作用（即更大的 ( \beta )）对应更大的 ( p_0 )，从而产生更小的潜热。因此，一级 DPT 可能在强耦合极限下转变为连续相变（continuous phase transition）。

[第4页，第13段] 临界行为也反映在其他物理量中。例如，考虑顶点 ( i ) 的局部聚类系数（local clustering coefficient）( C_i := \sum_{j,k} A_{ij} A_{jk} A_{ki} / k_i (k_i - 1) ) [43,44]。在 ( t_c ) 附近，非线性相互作用成为主导。四次相互作用（quartic interaction）意味着新三角形的数量近似随新边的数量线性增加。因此，与顶点 ( i ) 相连的三角形数量与其度成正比，即 ( \sum_{j,k} A_{ij} A_{jk} A_{ki} \sim k_i )。等价地，这导致当 ( t \to t_c ) 时 ( C \sim (1/k) )。该理论预测已通过数值模拟验证，如图 4(d) 所示。这种标度关系常见于具有模块化结构（modular structures）的网络中，例如许多由层次机制（hierarchical mechanisms）生成的真实世界网络 [45,46]。值得注意的是，在不依赖任何此类假设的情况下，

[第5页，第1段] 该DPT（动态相变）的临界行为自然遵循相同的规律。

[第5页，第2段] 讨论——我们在非平衡网络动力学中发现了一种DPT（动态相变），这一现象在已知的增长模型（如三元闭包模型[47]和复制模型[48]）中并不存在，这些模型未表现出有限时间奇异性。虽然我们的主要关注点是非平衡动力学，但当$t \to \infty$时达到的渐近稳态与常见的平衡系综密切相关。在最简单的线性情况（$\beta = 0$）下，稳态分布与Erdős-Rényi系综（Erdős-Rényi系综）一致；而在非线性相互作用（$\beta > 0$）下，它则与包含三角形项的Strauss型模型（Strauss型模型）[49-51]相关联（参见补充材料[38]第1.3节）。这些渐近态从稀疏到稠密的转变与Strauss凝聚（Strauss凝聚）现象一致。

[第5页，第3段] 另一方面，Strauss型模型通常会坍缩为均匀稠密结构，仅在临界点附近才显现异质性。相比之下，在我们的模型中，异质性在达到平衡之前就动态产生，并在临界时间$t_c$处导致有限时间奇异性，这与先前在平衡或增长模型[47-53]中研究的转变有本质区别。

[第5页，第4段] 这一视角也阐明了我们的结果对真实系统的相关性。在金融危机、疫情暴发、基础设施故障或社会动荡等情境中，干预措施通常在不稳定性出现时才会实施，因此系统可能永远无法达到其渐近平衡。实证研究[19]表明，在线社交动力学中的密度类度量表现出与方程(1)一致的明确双曲发散（hyperbolic divergence）。这一观察结果自然可由我们方程(5)的理论预测解释，凸显了瞬态非平衡动力学的核心作用以及有限时间奇异性的可能性。更广泛地说，我们的结果表明，动力学网络模型为捕捉复杂系统中的有限时间临界现象提供了一个自然框架。这种从平衡系综视角无法观察到的行为，可能在理解跨多个现实世界领域的突发不稳定性中发挥核心作用。

[第5页，第5段] 最后，这种最小经典设定中DPT（动态相变）的出现也暗示了与量子动力学相变（quantum dynamical phase transitions）的有趣相似性。在量子系统中，演化算符$U = e^{-\int Hdt}$是理解相变的核心，它将时间依赖率函数中的非解析性与$U$的特征值联系起来。在经典系统中，尽管缺乏幺正性（unitarity），演化算符的谱可能扮演类似角色。我们的最小模型为经典系统中出现DPT（动态相变）提供了一个具体实例，揭示了与量子DPT（动态相变）的相似性。SD方程（Schwinger-Dyson方程）作为捕捉非平衡动力学的强大工具，可能成为分析经典和量子DPT（动态相变）的统一框架，正如本快报及量子DPT（动态相变）研究[54]中所展示的。
