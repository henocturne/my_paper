[第1页，第5段]
现实世界系统常常在不同的时间尺度上演化，并具有多个共存的稳定态。系统在受到扰动偏离某一稳定态后能否返回该稳定态，取决于其吸引盆（basin of attraction）的形状和范围。我们表明，多尺度系统中的吸引盆可以表现出特殊的几何性质，即奇异漏斗（singular funnel）。尽管奇异漏斗很窄，但它们可以延伸到相空间的不同区域，并且出人意料地影响系统对扰动的韧性。因此，奇异漏斗可能会阻碍在大时间尺度分离极限下常用的降维方法，如准静态近似（quasistatic approximation）、绝热消去（adiabatic elimination）和快变量的时间平均。我们将具有奇异漏斗的吸引盆称为奇异吸引盆（singular basin）。我们表明奇异吸引盆具有普遍性，并在一系列多尺度系统中稳健地出现：具有缓慢适应参数的叉式分岔（pitchfork bifurcation）的标准形、自适应主动旋转子（adaptive active rotator），以及自适应相位旋转子网络。

[第1页，第7段]
复杂的现实世界系统具有多稳定性（multistability）的特征；即，从不同的初始条件出发，同一系统可能最终表现出显著不同的渐近行为。多稳定性的例子可以在癫痫和神经元模型[1,2]、储备池计算机[3]、激光器[4,5]和气候[6,7]等中找到，仅举几例。因此，多稳定性相关现象的分析与控制已成为许多研究的主题[8–10]。多稳定系统中的一个重要问题涉及不同稳定态之间可能的转变。应对上述挑战的一个著名方法是吸引盆稳定性（basin stability）的概念[11,12]，它表示从随机初始条件出发到达给定状态（吸引子）的可能性。这种可能性可以通过其吸引盆的相对体积来估计，即相空间中收敛到该吸引子的初始状态的比例。更重要的是，吸引盆的形状决定了系统对扰动的不确定性[13]和韧性[14,15]。因此，要理解和控制多稳定系统，理解其吸引盆的几何结构至关重要。

[第1页，第8段]
除了具有多个稳定态之外，现实世界系统也常常在多个时间尺度上演化，这产生了各种非线性现象[16–20]。多尺度系统的一个重要例子是自适应动力网络（adaptive dynamical network），其中适应过程比节点动力学慢得多[21–26]。这类系统具有挑战性，因为它们也是高维的，并且可能表现出高度的多稳定性。多尺度系统中吸引盆的研究是一个在很大程度上仍未被探索的研究领域。因此，揭示由不同时间尺度相互作用产生的吸引盆的新性质是一项引人入胜且重要的任务。

[第1页，第9段]
已有用且广泛使用的技术被开发用于分析具有两个不同时间尺度的多尺度系统（也称为慢-快系统（slow-fast system））的数学模型[27–29]。这些技术利用了快慢时间尺度之间无限比值的极限，可以大致分为两组[16,30,31]。第一组包括绝热消去和平均。它通过将快变量视为瞬时的，或考虑其有效贡献，来消除快变量，同时在约化系统中仅考虑慢变量的时间演化。第二组包括准静态近似。它通过在每个瞬间将慢变量视为静态来“冻结”慢变量，同时在层系统中仅考虑快变量的时间演化[16,28]。

[第1页，第10段]
本文揭示了慢-快系统中吸引盆的特殊性质，从而引出反直觉的

[第2页，第1段]
现象。我们表明，此类盆地可以包含奇异漏斗（SFs），其形式为延伸到相空间不同区域的隧道，并且随着时间尺度比的增加而变得越来越窄。SFs 的问题在于它们被准静态近似和绝热消去所消除。因此，绝热消去使得无法从相空间的某些区域到达给定的稳定状态，而在完整系统中这是可能的。另一方面，准静态近似可能完全掩盖多个吸引盆的存在。因此，当从简化系统的韧性特性推断完整系统的韧性特性时，必须谨慎，无论后者是通过准静态近似、绝热消去还是平均法获得的。由于在时间尺度比无穷大的极限下 SFs 消失，我们将包含 SFs 的盆地称为奇异盆地。

[第2页，第2段]
我们首先说明 SFs 在具有缓慢适应分岔参数的超临界叉式分岔的正常形式中的惊人效应。仅正常形式由 $dx/dt = x(\mu - x^2)$ [32] 给出。我们限制 $x \geq 0$，这对许多应用是合适的，例如，当变量 $x$ 表示种群密度或某个可观测量的幅度时。这样的系统有一个单一的稳定平衡 $x^*$，它对所有 $\mu$ 值连续存在。具体来说，对于 $\mu \leq 0$，$x^* = 0$；对于 $\mu > 0$，$x^* = \sqrt{\mu}$，因此它可以更紧凑地写为 $x^*(\mu) = \sqrt{\mu H(\mu)}$，其中 $H(\mu)$ 是 Heaviside 阶跃函数 [33]。然后我们以分岔参数 $\mu$ 的线性适应的形式引入慢变量，得到以下以快时间 $t$ 表示的慢-快系统：

[第2页，第3段]
$$\frac{dx}{dt} = x(\mu - x^2), \tag{1}$$

[第2页，第4段]
$$\frac{d\mu}{dt} = \epsilon(-\mu + ax - b). \tag{2}$$

[第2页，第5段]
小参数 $0 < \epsilon \ll 1$ 是 $\mu$ 的慢时间尺度与 $x$ 的快时间尺度之间的比率。当 $\epsilon = 0$ 时，慢时间尺度无限慢，或者等价地，快时间尺度无限快。参数 $a, b > 0$ 决定适应规则。在条件 $a > 2\sqrt{b}$ 下，系统 (1)–(2) 有两个稳定平衡 $e_1$ 和 $e_3$，一个鞍平衡 $e_2$，以及一个 SF，如图 1(a) 所示；更多细节见参考文献 [34]。

[第2页，第6段]
层系统通过在 (1)–(2) 中设置 $\epsilon = 0$ 获得，这给出了具有静态 $\mu$ 的系统 (1)。它有一个唯一的稳定准静态平衡 $x^*(\mu)$，它随 $\mu$ 连续变化，并在每个 $\mu$ 值处吸引所有初始条件 $x_0 > 0$ [图 1(a) 中灰色曲线 $S$ 的实线部分]。因此，我们应用绝热消去程序。我们因此将 $x^*(\mu)$ 代入 (2)，定义慢时间为 $\tau = \epsilon t$，并以 $\tau$ 表示获得简化系统，

$$\frac{d\mu}{d\tau} = f(\mu), \tag{3}$$

[第2页，第9段]
其中 $f(\mu) = -\mu + a\sqrt{\mu H(\mu)} - b$。然后我们认识到这是一个具有双势阱的双稳态动力系统，

[第2页，第10段]
$$U(\mu) = -\int f(\mu)d\mu = \mu^2/2 + b\mu - 2a[\mu H(\mu)]^{3/2}/3 \tag{10}$$

[第2页，第11段]
并且与完整系统具有相同的平衡；见图 1(b)。在绝热消去后，图 1(b) 中稳定平衡 $e_1$ 和 $e_3$ 的吸引盆被慢变量的单个值 $\mu = \mu_b$ 清晰地分开，该值由不稳定平衡 $e_2$ 的位置给出。如果简化系统从 $\mu_b$ 的左侧（右侧）开始，它只能收敛到 $e_1$（$e_3$）。然而，有一个意外。由于 SF，这种由 $\mu = \mu_b$ 清晰分开的盆地在完整系统 (1)–(2) 中从未出现，无论时间尺度比有多大（或 $\epsilon$ 的值有多小但非零）。特别地，SF 允许从 $\mu_b$ 的两侧收敛到 $e_1$，这在简化系统中是不可能的。这包括沿快 $x$ 方向从 $e_3$ 进入 SF 的扰动。从简化系统的角度来看，这看起来像是从 $e_3$ 到 $e_1$ 的类量子“隧穿”或“瞬移” [图 1(b) 中的灰色箭头]。总之，SF 明显限制了绝热消去的适用性，尽管层系统具有唯一的稳定准静态平衡，它随 $\mu$ 连续变化，并在每个 $\mu$ 值处吸引所有初始条件 $x_0 > 0$。为了证明系统 (1)–(2) 的全局绝热消去失败不是由 $(\mu, x) = (0, 0)$ 处的退化引起的，补充材料 [34] 提出了一个没有这种退化但仍具有 SF 的修改系统。

[第3页，第1段]
范式模型(1)–(2)中的SF具有非常简单的几何结构。然而，一般而言，SF可以具有复杂的几何结构，并能以复杂的方式穿透另一个稳定态的（白色）吸引盆。我们现在将针对自适应相位旋转器来展示这一点。

[第3页，第2段]
快慢自适应相位旋转器具有以下形式[35]

[第3页，第3段]
$ 
\frac{d\varphi}{dt} = \omega + \mu - \sin \varphi,
 $

[第3页，第4段]
$ 
\frac{d\mu}{dt} = \varepsilon \{-\mu + \eta [1 - \sin(\varphi + \alpha)]\},
 $

[第3页，第5段]
其中$ \varphi \in (0, 2\pi] $是相位变量，$ \omega $是基础振子频率，$ \mu $表示振子频率的缓慢自调整。具有静态$ \mu $的层系统(4)在$ |\omega + \mu| < 1 $时有一对平衡点，一个吸引、一个排斥，在$ |\omega + \mu| > 1 $时存在周期旋转[36]。在点$ |\omega + \mu| = 1 $处，层系统经历不变圆上的鞍结分岔[37–40]。因此，当$ |\omega + \mu| \leq 1 $时，层系统(4)具有唯一的吸引准静态平衡点，它随$ \mu $连续变化，并在每个$ \mu $值处吸引所有初始条件（排斥平衡点除外）。当$ |\omega + \mu| > 1 $时，吸引平衡点被存在的周期旋转所取代。

[第3页，第6段]
自适应相位旋转器(4)–(5)也可以通过消去快变量$ \varphi $简化为形式(3)。这通过对$ |\omega + \mu| > 1 $时的快速旋转进行平均，以及对$ |\omega + \mu| < 1 $时进行绝热消去来实现。简化系统(3)的相应函数$ f(\mu) $可以显式计算[34]：

[第3页，第7段]
$ 
f(\mu) = -\mu + \eta [1 - (\mu + \omega) \cos \alpha + \Omega(\mu)],
 $

[第3页，第8段]
其中

[第3页，第9段]
$ 
\Omega(\mu) = \begin{cases} -\sqrt{1 - (\mu + \omega)^2} \sin \alpha & \text{for } |\mu + \omega| \leq 1 \\ \sqrt{(\omega + \mu)^2 - 1} \cos \alpha & \text{for } \mu + \omega > 1 \\ -\sqrt{(\omega + \mu)^2 - 1} \cos \alpha & \text{for } \mu + \omega < -1. \end{cases}
 $

我们考虑系统(4)–(5)具有两个共存吸引子的情况：一个稳定平衡点$ e_1 $和一个稳定旋转$ \gamma_c $；更多细节见图2(a)和[34]。简化系统(3)在$ f(\mu) $由式(6)给出时，也是一个具有双势阱的双稳态系统，如图2(b)所示。

[第3页，第11段]
图2(a)和2(c)中自适应相位振子[系统(4)–(5)]的奇异盆具有一个延伸到负$ \mu $区域的SF。这形成了一条通道，通过该通道，具有任意$ \mu $和选定$ \varphi $的初始条件被吸引到周期旋转$ \gamma_c $。再次强调，这在简化系统(3)的框架内是不可能的，其中只有$ \mu > \mu_b $的初始条件才能收敛到平均周期旋转$ \gamma_c $；见图2(b)。

[第3页，第12段]
我们在此强调，自适应相位振子[系统(4)–(5)]的SF几何结构比自适应叉式规范形(1)–(2)更为复杂。主要差异如下。(i) 在图2中，SF延伸到相位变量$ \varphi $的整个范围，而图1中$ x $变量的区域是指数小的。(ii) 图1中的SF随$ \mu $指数衰减，$ \mu $增大至无穷，而在图2中，这种指数衰减仅发生在有限的$ \mu $区间内。这导致系统(4)–(5)的SF体积比系统(1)–(2)更大。为了更好地理解系统(4)–(5)的SF几何结构，我们在补充材料[34]中包含了变量$ \varphi $显示在实线上的相图。

接下来，我们提供图2(a)和2(c)中SF边界如何形成的细节。与自适应叉式规范形系统(1)–(2)的情况一样，这些边界由被吸引到鞍平衡点$ e_2 $的轨道（$ e_2 $的稳定不变流形的分支）组成。对这些轨道进行时间反向追踪表明，它们经过层系统的不稳定准静态平衡点分支附近。这就是图2(a)和2(c)中曲线$ S $的虚线部分，其中$ S $也被称为临界流形[16]。由于临界流形的这部分在反向时间中是吸引的，两个SF边界

当它们被吸引到 $S$ 时，会以指数方式相互靠近，导致 SF 以指数方式变窄。当 SF 延伸越过 $S$ 到达负 $\mu$ 后，它会经历进一步的旋转，以复杂的模式反复与 $e_1$ 的白色吸引盆相交。

[第4页，第2段]
对于迄今为止所考虑的具有奇异吸引盆的系统，我们可以获得当 $\epsilon$ 趋近于 0 时 SF 体积如何收缩的普适标度律。在所有情况下，对应于 SF 边界的轨迹运动缓慢，其速度在临界流形 $S$ 的不稳定分支上正比于 $\epsilon$。因此，它们在长度为 $L$ 的 $S$ 的不稳定分支附近停留的时间按 $L/\epsilon$ 标度。SF 的宽度 $\delta$ 由两条靠近 $S$ 的轨迹（图 2 中的蓝色轨迹）决定。因此，$\delta$ 随时间反向呈指数衰减。所以，当 SF 离开长度为 $L$ 的 $S$ 的不稳定分支邻域时，该宽度可以估计为 $\delta \sim \exp(-L\lambda/\epsilon)$。这里 $\lambda$ 是远离 $S$ 的有效排斥率，对应于反向时间中的吸引。这些论证导出了对 SF 体积的以下预期标度律：

[第4页，第3段]
$$V(\epsilon) \sim \exp(-C\epsilon^{-1}), \quad C > 0. \tag{7}$$

[第4页，第4段]
标度律 (7) 对于自适应正规形系统 (1)–(2) 成立，因为 $e_2$ 的稳定流形从 $x = 0$ 处以指数方式被排斥。此外，自适应相位旋转器系统 (4)–(5) 也表现出这种标度律，如图 2(c) 所示。预期 SF 标度律 (7) 对大类慢-快系统成立，至少在低维情况下如此，因为导出 (7) 的论证基于吸引盆边界的相当一般的几何结构。然而，如下文所示，在高维系统中发现的具有更复杂几何结构的 SF 可能会偏离这种标度律。

[第4页，第5段]
一类可以观察到奇异吸引盆的高维系统是平均场耦合主动旋转器系统，

[第4页，第6段]
$$\frac{d\varphi_i}{dt} = \omega_i + \mu - \sin \varphi_i + \frac{\kappa}{N} \sum_{j=1}^{N} \sin(\varphi_j - \varphi_i), \tag{8}$$

[第4页，第7段]
$$\frac{d\mu}{dt} = \epsilon[-\mu + \eta(1 - X)], \tag{9}$$

[第4页，第8段]
其中 $i = 1, \ldots, N$ 且 $X = (1/N) \sum_{j=1}^{N} \sin(\varphi_j + \alpha)$。在该系统中，各个旋转器的频率由慢变量 $\mu$ 全局自适应调节，而 $\mu$ 由平均场 $X$ 驱动。与广泛研究的无自适应耦合旋转器系统 [10,41–47] 相比，自适应系统 (8)–(9) 以比率 $\epsilon$ 在两个不同的时间尺度上演化。类似性质的自适应系统已被证明表现出独特的动力学特性，如鸭翼级联 [18,48]、涌现兴奋性 [49] 等 [50–52]。在此，我们将奇异吸引盆加入这一独特性质列表。

我们观察到$V(\epsilon)$对某些$\Delta_\omega$值（例如$\Delta_\omega = 0.6$）遵循标度关系(7)，而对其他$\Delta_\omega$值，它表现出偏离(7)的类共振偏差（例如$\Delta_\omega = 1$或$\Delta_\omega = 2.2$）。因此，我们得出结论：高维系统可以具有偏离简单标度关系(7)的SF，并将此留作未来研究的问题。

[第5页，第3段]
通过二维截面可视化高维系统中的SF非常困难。相反，10个耦合转子情形（11维相空间）的SF估计体积绘制在图4(a)中。与低维例子类似，体积随$\epsilon$收缩，表明SF的存在。此外，图4(b)显示了两条轨迹：（红色）一条从SF出发并收敛到周期旋转，（蓝色）一条从附近出发并保持在非常接近的位置，但最终收敛到稳定平衡点$\epsilon_1$，这是SF的另一个迹象。

[第5页，第4段]
最后，奇异盆是一种鲁棒现象。这是因为其组成要素在小参数变化下持续存在。这适用于鞍平衡点的稳定不变流形和共存吸引子。我们在[34]中说明了奇异盆持续存在的广泛参数区域以及其可能被破坏的机制，以系统(4)–(5)为例。

[第5页，第5段]
总之，我们揭示了双稳态慢快系统中的奇异盆与奇异漏斗，并表明它们是鲁棒且普遍存在的。SF阻碍了有用且广泛使用的降维方法，即使在存在唯一准静态吸引子的情况下也是如此——该吸引子随慢变量连续变化，并在慢变量的每个冻结设置下吸引几乎所有初始条件。尽管对快变量进行绝热消去或平均在约化系统中保留了不同稳定态和不同吸引盆的共存，但完整系统的快动力学可以通过SF导致不同稳定态之间的转变，这在约化系统中是不可能的。从约化系统的角度来看，这些意外动力学类似于量子隧穿或从一个吸引子到另一个吸引子的瞬移。我们构造了低维规范系统，可视为奇异盆的标准型，并展示了这些系统中SF随时间尺度比增加的普适标度关系。此外，我们证明了SF可以在具有慢自适应平均场耦合的高维系统相空间中形成复杂结构。未来研究的一个挑战是理解具有两个以上时间尺度和两个以上共存稳定态的系统中的奇异盆。

[第5页，第6段]
也许最引人入胜的是，任何真实世界系统的数学模型必然是一种省略了某些快变量的近似。因此，我们的结果也为意外临界转变[53]的可能性提供了新见解。例如，由于省略了某些快变量而未被模型捕捉到的不同稳定态之间的转变，可能在真实系统中被触发。
