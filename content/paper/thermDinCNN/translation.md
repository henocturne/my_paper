[第1页，第4段]
深度神经网络（DNNs）是压缩和提炼信息的强大工具。其规模和复杂性，通常涉及数十亿个相互依赖的参数，使得直接的微观分析变得困难。在这种情况下，一种常见的策略是识别慢变量，这些变量平均了快速微观变量的不稳定行为。在这里，我们在完全训练的有限过参数化深度卷积神经网络（CNNs）和全连接网络（FCNs）中识别出类似的尺度分离现象。具体来说，我们表明DNN层仅通过其激活和预激活的二阶累积量（核）进行耦合。此外，后者以近乎高斯的方式波动。对于无限宽度的DNN，这些核是惰性的，而对于有限宽度的DNN，它们适应数据并产生一个可处理的、数据感知的高斯过程。由此产生的深度学习热力学理论在各种设置中产生准确的预测。此外，它提供了一般分析和理解DNN的新方法。

[第1页，第5段]
识别慢变量或相关变量是分析大规模非线性系统的基本步骤。在深度神经网络（DNNs）的背景下，这些应该是某些个体权重的组合，这些组合波动微弱并服从一组封闭方程。一组潜在的此类变量是DNN的输出本身。事实上，在无限过参数化DNN的极限下，这些变量基于映射到高斯过程（GPs）提供了深度学习的优雅图景¹–³。然而，这些GP极限遗漏了几个定性方面，例如特征学习⁴,⁵以及真实世界的DNN并不像GP描述所要求的那样过参数化¹,³,⁶,⁷。因此，在有限过参数化下获得一组用于描述深度学习的有效慢变量是该领域的一个重要开放问题。

[第1页，第6段]
几项工作为这一搜索提供了指导。注意到GP极限可以具有惊人的良好性能⁸，并且过参数化对深度学习是自然的⁹,¹⁰，我们倾向于保留GP图景的某些元素。其中一个元素是在函数空间中工作，研究预激活和输出，而不是权重，因为权重的后验分布即使在GP极限下也变得复杂¹¹,¹²。另一个元素是隐藏层核的逐层组合¹³，这产生了GP的输出核¹⁴。这种逐层图景也与DNN层不应强烈相关以防止共适应¹⁵的观点相协调。最近的研究表明，在一些有限的设置中，使GP核“动态”或灵活，使其适应数据集，可以解释无限和有限DNN之间的差异³¹⁶–¹⁹。尽管如此，在深度非线性DNN中找到描述这种灵活性的显式方程组仍然未解决。具体来说，虽然在GP极限中我们找到了可处理的代数表达式，仅涉及基本矩阵操作，但对于特征学习 regime 中的DNN预测，类似的表达式仅存在于深度线性¹⁶,²⁰或具有一个可训练层的非线性网络²¹–²³中。以相关的方式，虽然在GP极限中DNN的输出提供了一组完整的慢变量，但在有限宽度特征学习 regime 中，除了整个权重集之外，不清楚哪些变量子集支配训练后的DNN行为。

3. 我们识别出一个涌现的特征学习尺度（FLS），记为 $ \chi $，正比于训练MSE乘以 $ n^2 $ 除以 $ C $（或 $ N $）。该尺度控制有限 $ C, N $ 输出核（$ Q_f $）与其 $ C, N \to \infty $ 极限之间的差异，在此意义上反映了特征学习。由于 $ n^2 $ 因子，即使对于 $ C \gg 1 $，$ \chi $ 也可以为 $ O(1) $ 或更大，例如对于CNN架构（见图2面板c）。对于MF缩放下的FCN，将 $ C $ 替换为 $ N $ 后同样成立。与微扰理论不同，我们的理论追踪 $ \chi $ 的所有阶，仅将 $ 1/C, 1/N $ 作为微扰处理。因此，$ \chi $ 与 $ 1/C, 1/N $ 之间的尺度分离是我们分析的核心。其表现为：特征学习以可观的方式移动和拉伸理论中的动力学变量（预激活），但几乎不破坏其高斯性。

\left[ K^{(l-1)} \right]_{\mu \nu} = \left[ \left( Q^{(l-1)} \right)^{-1} \right]_{\mu \nu} + \frac{2N_l}{N_{L-1}} \frac{\partial D_{KL}(K^{(l)}) Q^{(l)}}{\partial K^{(l-1)}} \text{ for all } l \in [2L-1] \quad (S)
 $

[第4页，第5段]
$ 
\left[ \Sigma^{-1} \right]_{ss'} = \frac{d}{\sigma_1^2} \delta_{ss'} + \frac{2N_2}{N_1} \frac{\partial D_{KL}(K^{(2)}) Q^{(2)}}{\partial \Sigma_{ss'}}
 $

[第4页，第6段]
$ 
A^{(l)} = \sigma^{-4} (y - \tilde{f})(y - \tilde{f})^\top - \left[ Q_f + \sigma^2 I_n \right]^{-1}
 $

[第4页，第7段]
其中 $  [Q_f]_{\mu \nu} = \sigma_1^2 G(K^{(l-1)})_{\mu \nu}  $，$  [Q^{(l)}_{\mu \nu}]_{\mu \nu} = \sigma_1^2 G(K^{(l-1)})_{\mu \nu}  $，且对于矩阵 $  K \in \mathbb{R}^{n \times n}  $，有 $  G(K)_{\mu \nu} = \frac{2}{\pi} \sin^{-1} \left( \frac{2K_{\mu \nu}}{\sqrt{1+2K_{\mu \nu}} \sqrt{1+2K_{\nu \nu}}} \right)  $（若干常见激活函数（如ReLU$ ^4 $）的等价表达式是已知的）。此外，$  \tilde{f}  $ 是DNN的平均输出，$  D_{KL}(K||Q)  $ 是协方差矩阵为 $  K  $ 和 $  Q  $ 的两个高斯分布之间的KL散度。输入层后核为 $  K^{(1)} = X_n \Sigma X_n^\top  $，其中 $  \Sigma  $ 是输入层权重的协方差矩阵。

[第4页，第8段]
正如它们不依赖于宽度所表明的，第一个方程连同后核 $  Q^{(l)}, Q_f  $ 的定义已经出现在严格GP极限（$  N_l \to \infty  $）中。它们分别是采用erf激活的随机DNN$ ^4 $的GP推断公式和标准核递推方程。据我们所知，其余方程是新颖的，描述了有限 $  N_l  $ 下预核和后核的变化。这些方程在一些简单情形下可以解析求解（见“EoS的解析解——两层CNN情形下的两层CNN”小节）。我们注意到，对于非反对称激活，还需要追踪每一层预激活的均值（见补充材料（S））。

[第4页，第9段]
为了对其作用获得定性印象，可以考虑倒数第二层（$  l = L-1  $）为线性的情形，此时 $  Q_f = \sigma_1^2 K^{(L-1)}  $。因此，$  \frac{\partial [Q_f]_{\mu \nu}}{\partial [K^{(L-1)}]_{\mu \nu}} = \sigma_1^2 \delta_{\mu \nu} \delta_{\nu \nu}  $（其中双下标 $  \delta_{\mu \nu}  $ 在此指克罗内克δ），于是第二个方程简化为

[第4页，第10段]
$ 
\sigma_1^2 Q_f^{-1} = (Q^{(L-1)})^{-1} - \frac{\sigma_1^2}{N_{L-1}} \left( \epsilon \Sigma^\top - [Q_f + \sigma^2 I_n]^{-1} \right),
 $

[第4页，第11段]
其中 $  \epsilon = (y - \tilde{f})/\sigma  $。我们顺便指出，即使对于非线性倒数第二层，将 $  Q_f  $ 在 $  K^{(L-1)}  $ 中展开到线性阶也会产生类似的项。从上述形式可以得出若干见解。

[第4页，第12段]
首先，我们认为上述方程意味着，与 $  N_{L-1} \to \infty  $ 时的DNN相比，训练后的DNN对沿 $  \epsilon  $ 方向的变化更为敏感。注意到 $  Q_f^{-1}  $ 如何进入作用量（式(3)），它控制着与 $  f  $ 涨落相关的刚度。因此，$  Q_f^{-1}  $ 使得沿 $  \epsilon  $ 方向的涨落比根据 $  (Q^{(L-1)})^{-1}  $ 所预期的更可能发生。由于 $  \epsilon  $ 衡量训练预测的偏差，这一效应通过使DNN在这些方向上比在 $  N_{L-1} \to \infty  $ 时更具响应性来减小偏差。第二项与 $  \left[ Q_f + \sigma^2 I_n \right]  $ 成正比，相当于沿 $  Q_f  $ 的对应于大于 $  \sigma^2  $ 的特征值的特征向量方向的涨落发生可忽略的减小。

[第4页，第13段]
利用式(6)还可以识别出前述涌现的特征学习尺度（feature learning scale，FLS），即 $  \chi = N_{L-1} \epsilon^\top Q^{(L-1)} \epsilon  $。该尺度表示将 $  Q_f  $ 按 $  1/N_{L-1}  $ 进行泰勒展开时主导项的大小。当 $  \chi = O(1)  $ 或更大时，$  Q_f  $ 的特征值与 $  Q^{(L-1)}  $ 相比发生显著变化，这表明存在特征学习。另一方面，当该量较小时，我们更接近GP区域（见补充材料（I.6））。为了评估 $  \chi  $ 的标度，可以考虑常见情形：$  \epsilon  $ 与 $  Q^{(L-1)}  $ 的主导特征向量有不可忽略的重叠，这些特征向量的特征值在尺度 $  \lambda  $ 上。这里我们发现 $  \chi \approx \lambda \cdot \text{MSE}/\sigma^2 \cdot n/N_{L-1}  $，其中MSE表示平均训练MSE，通过 $  ||\epsilon||^2/n  $ 进入此处。由于其显式的 $  n  $ 依赖性，并且在 $  n  $ 很大时 $  \lambda = O(n)  $，即使在非常大的 $  N_{L-1}  $ 下和/或平均MSE相当小时，$  \chi  $ 也可能为 $  O(1)  $。

[第4页，第14段]
图2c展示了对于我们研究的若干DNN，$  \chi = 1  $ 时的 $  N_{L-1}  $（或 $  C_{L-1}  $）值（即特征学习成为主导效应时的 $  N_{L-1}  $ 或 $  C_{L-1}  $）作为 $  n  $ 的函数。图中展示的尺度分离——即 $  \chi  $ 在 $  1/N_s  $ 可忽略的区域仍可为 $  O(1)  $——是我们分析方法的中心。

[第4页，第15段]
这个尺度 $  \chi  $ 也是朴素的 $  1/N_l  $ 微扰理论在大 $  n^{3.6,23,27}  $ 下失效的原因，因为它将 $  \chi  $ 和 $  O(1/N_{L-1})  $ 同等对待，而二者都只含有 $  N_{L-1}  $ 的一次负幂。相比之下，我们的EoS以非微扰方式处理FLS。

[第4页，第16段]
最后，我们强调EoS为我们提供了对整个DNN及其隐藏层的具体、有效的GP描述。先验地，人们会预期预激活的正态性——一种大 $  C, N  $ 特性——会在有限 $  C, N  $ 下丧失。然而，我们发现预激活保持高斯分布，并在保持准确预测的同时容纳了强烈的特征学习效应。这种出乎意料的简单行为开辟了各种逆向工程的可能性，即从实验中推断有效核，并利用其谱和特征向量来对DNN进行合理化解释（另见图5）。就此而言，我们评论道，将EoS扩展到测试点是直接的：形式上把测试点视为具有其自身“噪声”参数的额外训练点，然后将其发送到无穷大（见补充材料（I.4.1））。包含测试点的具体EoS表达式，见“EoS的解析解——两层CNN”一节。

[第4页，第17段]
**数值演示：3层FCN**

[第4页，第18段]
接下来，我们检验上述结果和陈述与实际训练DNN之间的一致性，从式(1)中定义、$  L = 3  $ 的3层FCN开始。我们在此关注师生设置，训练数据点数为 $  n = 512  $ 或1024，从每个输入维度单位方差的独立同分布高斯分布中抽取。目标由同类型的随机抽取的教师FCN生成，仅 $  N_1 = N_2 = 1  $。学生使用类似于MF缩放$ ^2 $的模拟缩放进行训练，其中输出层权重按因子 $  1/\sqrt{N_l}  $ 缩小。虽然对于下面讨论的CNN不需要这种缩放选择，但对于FCN，我们发现这是在 $  N_1 = N_2 = N \gg 1  $ 时获得任何可察觉的特征学习所必需的（图2c）。

[第4页，第19段]
如方法部分所述，我们使用Langevin算法训练了20个FCN，直到它们达到平衡。我们使用这些训练好的FCN来计算我们配分函数（式(3)）下的各种平均量。具体而言，我们关注：(i) 在 $  \sigma^2  $ 尺度上的归一化训练损失，即 $  \text{MSE}/(\sigma^2 \sum_{\mu} \nu_{\mu}^2)  $；(ii) 平均 $  \Sigma  $ 的特征值 $  (\lambda_i, i \in [1..d])  $，其中我们对神经元、训练种子和训练时间（后者在平衡区域内）进行平均；(iii) 归一化重叠 $  (\alpha)  $，介于

[第5页，第1段]
训练集上预测的偏差乘以目标，即 $\alpha = \sigma^{-2} \sum_{u=1}^{N} (\hat{f}_u - y_u) y_u / (\sum_{u} y_u^2)$。然后我们使用基于 JAX 的数值求解器求解 EoS（状态方程），并将其与实验进行比较。

[第5页，第2段]
如图 2b 的结果所示，随着我们增加 $N$，我们的 EoS 对这三个量的预测都很好地收敛了。此外，它们收敛的区域与它们相关的 GP（高斯过程）极限有相当大的差异。事实上，如补充材料 (3) 所示，最大的 $\Sigma$ 特征值比 GP 极限中的值大 2–3 倍。相关的特征向量对应于教师网络的第一层权重（$\mathbf{w}$）。其余特征值保持在它们的 GP 极限值。综合来看，这是强特征学习的明确标志。

[第5页，第3段]
然而值得注意的是，这种特征学习的概念不涉及压缩。事实上，由于 $\Sigma$ 在垂直于 $\mathbf{w}$ 的方向上与 GP 极限具有相同的方差，它不会通过仅将输入投影到标签相关方向（$\mathbf{w}$）上来压缩输入。相反，它夸大了学生权重沿 $\mathbf{w}$ 方向的波动，从而使得 $\mathbf{w} \cdot \mathbf{x}_u$ 和 $\mathbf{w} \cdot \mathbf{x}_v$ 符号相反的 $h_{uv}^{(1)}$ 和 $h_{uv}^{(1)}$ 在预激活空间中更有可能相距更远。

[第5页，第4段]
接下来，我们研究 $\chi$ 在不同架构下作为 $n$ 和 $C$（或 $N$）的函数的行为。图 2 显示了 $\chi = 1$ 时的 $N$（或 $C$）值。由于 $\chi$ 在该值的十倍处包含 $C$ 的单个逆幂，$\chi$ 将为 0.1，从而表明我们的 EoS 中只有轻微的特征学习效应。当 $N$、$C$ 从后一个值减小时，我们的 EoS 产生越来越强的特征学习效应。我们发现，对于标准缩放下的 CNN 和 MF（平均场）缩放下的 FCN，向特征学习的交叉都发生在我们的平均场解耦的有效区域内（即大 $N$ 或 $C$）。相比之下，标准缩放下的 FCN 在 $N = O(1)$ 时显示这种交叉，这超出了我们理论的范围。在这方面，我们评论说有证据表明标准缩放的 FCN 不如平均场缩放的 FCN$^{38}$，并且表现与 GP 相似$^{34}$。

[第5页，第5段]
**EoS 的解析解——两层 CNN**

[第5页，第6段]
在数值测试了我们的 EoS 之后，我们转而展示它们在简单设置下适合进行完全解析计算。除其他事项外，这将充实我们结果的非微扰性质。为此，我们考虑一个简单的两层非线性 CNN。虽然已经推导了一些界限$^{39,40}$，但我们不知道有任何关于有限非线性两层 DNN 性能的解析预测，更不用说 CNN 了。因此，这是我们方法的自然首次应用。具体来说，我们考虑

[第5页，第7段]
$$f(\mathbf{x}) = \sum_{i=1}^{N} \sum_{c=1}^{C} a_{ic} \text{erf}(\mathbf{w}_c \cdot \mathbf{x}_i) \tag{7}$$

[第5页，第8段]
其中 $\mathbf{x} \in \mathbb{R}^d$，$d = NS$，$\mathbf{w}_c, \mathbf{x}_i \in \mathbb{R}^S$。向量 $\mathbf{x}_i$ 由 $\mathbf{x}$ 的第 $iS, \ldots, (i+1)S-1$ 个坐标给出。数据集由 $\{\mathbf{x}_u\}_{u=1}^N$ 个独立同分布样本组成，每个样本 $\mathbf{x}_u$ 是一个协方差为 $I_d$ 的中心高斯向量。我们选择形式为 $y_u = \sum_i a_i^T (\mathbf{w} \cdot \mathbf{x}_u)$ 的线性目标，其中 $a_i \sim \mathcal{N}(0,1/N)$ 且 $\mathbf{w}_s \sim \mathcal{N}(0,1/S)$。这个选择并不关键，但大大简化了计算中的 GP 推断部分。我们使用 Langevin 算法训练这个 DNN，并调整权重衰减和梯度噪声，使得在没有任何数据的情况下，$a_{ic} \sim \mathcal{N}(0, \sigma_a^2 (NC)^{-1})$ 且 $[\mathbf{w}_c]_s \sim \mathcal{N}(0, \sigma_w^2 S^{-1})$。

[第5页，第9段]
状态方程由下式给出（见补充材料 (3)）

[第5页，第10段]
$$\mathbf{f} = Q_1 [\sigma^2 I_n + Q_1]^{-1} \mathbf{y} \tag{8}$$

[第5页，第11段]
$$\begin{bmatrix} Q_f \end{bmatrix}_{uv} = \frac{\sigma_a^2}{N} \sum_i G(\mathbf{x}_i \mathbf{x}_i^T)_{u,v} \tag{9}$$

[第5页，第12段]
$$\begin{bmatrix} \Sigma^{-1} \end{bmatrix}_{ss'} = \frac{S}{\sigma_w^2} \delta_{ss'} - \frac{1}{C} \text{Tr} \left\{ (\mathbf{e} \mathbf{e}^T - K_f)^{-1} \frac{\partial Q_f}{\partial \Sigma_{ss'}} \right\} \tag{10}$$

[第5页，第13段]
这里我们用 $\epsilon = (\mathbf{y} - \mathbf{f}) / \sigma^2$ 表示与目标的偏差。上述关于 $\Sigma_{ss'}$ 和 $\delta_{ss'}$ 的方程可以数值求解。一旦获得 $\Sigma_{ss'}$，将 EoS 推广到测试点就很直接（见补充材料 (1.4.1)），相当于用 $Q_f$ 进行 GP 推断。特别地，为了获得测试点 $\mathbf{x}_*$ 和训练点 $\mathbf{x}_v$ 之间所需的 $Q_f$ 值，需要计算 $2\sigma_a^2 \sum_i \sin^{-1} \left( \frac{2\mathbf{x}_i \mathbf{x}_i^T}{\sqrt{1+2\mathbf{x}_i \mathbf{x}_i^T} \sqrt{1+2\mathbf{x}_i \mathbf{x}_i^T}} \right) / (\pi N)$。训练和测试损失的结果在图 3 中以实线显示，与经验值吻合良好。

[第5页，第14段]
为了获得完全解析的结果，我们对大 $n$ 进行了若干近似。首先，我们基于矩阵 $[Q_f]_{uv}$ 的连续核版本 $Q_f(\mathbf{x}, \mathbf{x}')$ 来近似其谱。这与等效核$^{41}$近似密切相关，我们在此采用该近似及其主导阶修正$^{36}$。类似地，我们利用大 $n$ 将双重求和 $\sum_{u,v} \epsilon_{uv} \epsilon_{uv}^T [Q_f]_{uv}$ 替换为对 $\mathbf{x}_u$ 所抽取的测度（$d\mu$）的两个积分。见

[第6页，第1段]
补充材料 (3.1) 以获取更多细节以及关于全连接情形（$N=1$）的讨论。

[第6页，第2段]
根据我们的近似，方程获得了数据集测度的完全旋转对称性，这相当于对每个 $x_i$ 进行独立的正交变换。此外，如补充材料 (3) 所示，在大的 $S$ 下，给定线性目标 $y(x)$，$\bar{f}(x)$（代表 $f_\mu$ 的连续函数）是线性的，与 $x$ 无关，因此 $\epsilon(x)$ 也是如此。上述对称性进而意味着 $\epsilon(x)$ 仅是 $w \cdot x_i$ 的函数，并且进一步呈现简单形式 $\epsilon(x) = \alpha y(x)$。因此，量 $\alpha$ 衡量了预测差异（e）与目标之间的重叠。据此，EoS 被简化为关于单变量 $\alpha$ 的非线性方程

[第6页，第3段]
$$\sigma^2 \alpha = 1 - \frac{q_{\text{train}} S \lambda_\infty l}{S \lambda_\infty l + \sigma^2 / n}$$  \hspace{1cm} (9)

[第6页，第4段]
其中 $l_s = [1 - \chi_2]^{-1}/S$，$\chi_2 = C^{-1} \alpha^2 n^2 \lambda_\infty$，且 $\lambda_\infty$ 是 $Q_f(x, x')$ 在 $C \to \infty$ 极限下与线性函数相关的主特征值，$l_s$ 是与 $w$ 相关的 $x$ 的特征值（其余特征值是惰性的且等于 $1/S$），$\chi_2$ 是 2 层 CNN 的 FLS，并且我们假设 $||\mathbf{a}^*||^2 = ||\mathbf{w}^*||^2 = \sigma_0^2 = \sigma_w^2 = 1$（参见补充材料 (3) 以获取更一般的表达式）。量 $q_{\text{train}}$ 在等效核极限下恰好为一，其微扰修正（在 $1/n$ 中）可在补充材料 (3) 中找到。

[第6页，第5段]
求解上述关于 $\alpha$ 的方程，可以得到 $l$，进而得到 $x$ 以及 $Q_f$（通过 Eq. (8)）。使用得到的 $Q_f$，可以计算 DNN 在测试集上的预测。FLS 的影响在第二个方程中显而易见，它控制了偏离 GP 极限的程度。这里我们还回顾，$\alpha^2$ 是训练 MSE 除以 $\sigma^4$，因此如上定义的 $\chi_2$ 包含了引言中提到的 MSE 因子。

[第6页，第6段]
为了检验理论预测，我们训练了两个这样的 CNN，参数为 $n = [800, 1600]$；$S = 64$；$N = 20$ 以及变化的通道数。图 3 左图展示了 $\alpha$ 的经验测试集值（点）与状态方程的数值解（实线）及其解析解（虚线）的比较。对于后者，我们解析地获得了 $x$，并用 $Q_f$ 数值执行了所得的 GP 推断。插图追踪了训练集结果，在这种情况下，这些结果完全是解析的，不涉及数值 GP 推断。两种预测都与经验值相当吻合，即使在测试均方根误差大约为高斯过程（$C \to \infty$）一半的区域也是如此。右图展示了输入层权重，分别与 $w/||w||$ 和归一化随机向量进行点积。这些权重在微小的统计噪声范围内保持高斯分布。更多细节可在方法部分找到。

[第6页，第7段]
为了强调我们 Eq. (9) 的非微扰性质，让我们为了反驳而假设它们与 $1/C$ 的一阶微扰理论一致（如参考文献 3,6,23,24 中那样）。如果是这样，我们可以将上述 $\chi_2$ 表达式中的 $\alpha$ 替换为其 GP 值，因为它已经包含了一个 $C$ 的负幂次，因此在该阶不会收到进一步的修正。数值显示，对于 $n = 1600$，该值为 $\alpha_{GP} = 0.558$。代入此值，得到 $l = \frac{2}{3} [1 - 633.2/C]^{-1}$。显然，除非 $C \gg 633.2$，否则这一逻辑会导致矛盾。相比之下，我们的理论对于 $n = 1600$、$C = 320$ 和 $C = 640$ 提供了高度准确的预测，远非 $\frac{2}{3} [1 - 633.2/C]^{-1}$ 允许 $1/C$ 微扰理论的范围。在补充材料 (6.2) 中，我们报告了关于 $l$ 相对于其 GP 值的额外结果。

[第6页，第8段]
**向更深层 CNN 和真实世界数据集子集的扩展**

[第6页，第9段]
对于真正深层的 CNN 和真实世界数据集，即使在 $C \to \infty$ 极限下，获得 DNN 性能的完全解析预测也是一项具有挑战性的任务。尽管如此，EoS 可以通过数值求解并与实验值进行比较。此外，支撑它们的量可以被检验和推理。我们在此在两个更丰富的设置中进行研究：一个是用教师 CNN 训练的 3 层 CNN，另一个是在 CIFAR-10 子集上训练的 Myrtle-5 CNN$^{42}$。我们的第一个设置通过增加一个额外的激活层和一个由类似的非线性教师网络生成的目标函数来扩展前一节的内容，但该教师网络只有一个通道。更多细节，请参见“三层 CNN 模型定义”部分。

[第6页，第10段]

**讨论**

[第7页，第8段]
在这项工作中，我们提出了据我们所知，一个新颖的平均场框架，用于分析特征学习机制中的有限深度非线性神经网络。我们分析的核心是一系列平均场近似，揭示了预激活在层间弱相关，并在每层内遵循具有预核$ K^{(0)} $的高斯分布。使用后者与由上游层诱导的后核$ Q^{(0)} $一起，给出了控制隐藏层统计的显式状态方程（EoS）。这些使我们首次能够为特征学习机制中的非线性CNN和深度非线性FCN的性能推导出分析预测。我们进一步注意到，我们的EoS直接推广到组合CNN-FCN架构、ReLU激活函数（见补充材料5）、池化层以及具有多个输出的模型。我们找到的方程所表示的GP是大型但有限宽度贝叶斯神经网络生成的真实后验分布的良好近似。因此，在BNN的其他优势中，提供可靠的不确定性估计和有原则的模型比较$ ^3 $，它们也可能通过有效GP获得具体解释。

[第7页，第9段]
这项工作的各个方面值得进一步研究。从经验上讲，更好地表征贝叶斯采样器（或潜在的集成平均NTK动力学）导致高斯预激活和整体GP样行为的模型范围将是有趣的。通过实验测量核$ Q^{(0)} $和$ K^{(0)} $之间的差异来探测每层的“特征学习负载”，也可能为泛化、迁移学习和剪枝提供见解，从而补充最近建议的其他诊断工具$ ^3 $。例如，迁移具有小特征学习负载的层可能提供很少的好处，而剪枝与$ K^{(0)} - Q^{(0)} $的主导特征值有大量重叠的通道可能是有害的。

[第7页，第10段]
从理论方面，开发求解EoS的分析技术以及关于解的存在性和唯一性的保证是可取的。特别是，探索内部对称性自发对称破缺的可能性，例如

[第8页，第2段]
**方法**

[第8页，第3段]
**平均场作用量**

[第8页，第4段]
这里我们介绍我们理论的主要组成部分，从而得出我们发现的EoS。更多细节可在补充材料中找到。

[第8页，第5段]
**层和神经元的解耦。** 首先，我们将Eq. (3)解耦为逐层逐神经元的项，其中每一项仅通过激活和预激活的通道平均二阶累积量（预核和后核）依赖于上游和下游层。更多细节见补充材料(1)。

[第8页，第6段]
考虑Eq. (3)中作用量中耦合不同层的非线性项。这种耦合是通过通道/宽度平均量介导的：实际上，$  h^{(1)}  $通过$  h^{(2)}  $中的通道/宽度平均平方项依赖于$  h^{(2)}  $，$  h^{(2)}  $通过$  \phi(h^{(1)})\phi(h^{(1)})  $的平均依赖于$  h^{(1)}  $，而$  h^{(3)}  $通过$  \phi(h^{(2)})\phi(h^{(2)})  $的平均依赖于$  h^{(2)}  $，依此类推。对于$  N_l \gg 1  $，我们期望这些量波动微弱，并且可以通过其平均场值很好地近似。这种行为传播到输出层，特别地意味着从初始层在其均值或方差中的任一个或两者，这是特征学习的标志。通常，我们发现高斯性随层的深度增加（即下游层比上游层更高斯），并且随我们投影的特征向量索引增加（例如，这里投影到第10个特征向量比第1个特征向量更高斯）。更多细节可在补充材料(6.3)中找到，其中我们还展示了不同层之间以及每层内不同通道之间的相关性很小，从而证明在我们的理论中忽略这些是合理的。

[第8页，第7段]
输出$  f  $以高斯方式波动，如前所推测。至于$  h^{(l-1)}  $对$  f  $变量的依赖性，它不是通过通道/宽度平均量。然而，我们发现在各种场景中，例如具有MF缩放的FCN或具有大$  N  $的CNN，$  f  $的波动被抑制，使我们能够用其平均值替换$  f  $（见补充材料(1.7)和(2.2)）。据此，我们得到我们的平均场作用量，

[第8页，第8段]
$ 
\mathcal{S}_{\text{MF}} = \sum_{l=1}^{L-1} \mathcal{S}_{\text{MF}}^{(l)} + \mathcal{S}_{f, \text{MF}}.
 $ (10)

[第8页，第9段]
这允许我们定义关于分布的$  \langle \ldots \rangle_{\text{MF}}  $：$  n_{\text{MF}}((h^{(l)})_{l=1}^{L}, f) = e^{-\mathcal{S}_{\text{MF}} / \mathcal{Z}_{\text{MF}}},  $ 和配分函数$  \mathcal{Z}_{\text{MF}} = \int \prod_{l=1}^{L-1} dh^{(l)} df n_{\text{MF}}((h^{(l)})_{l=1}^{L}, f)  $。使得

[第8页，第10段]
$ 
\mathcal{S}_{f, \text{MF}} = \frac{1}{2\sigma^2} \sum_{\mu} (f_{\mu} - y_{\mu})^2 + \sum_{\mu \nu} \frac{1}{2} f_{\mu} [Q]_{\mu \nu}^{-1} f_{\nu},
 $ (11)

[第8页，第11段]
$ 
\mathcal{S}_{\text{MF}}^{(l)} = \frac{1}{2} N_{l+1} \sum_{\mu \nu} A_{\mu \nu}^{(l+1)} \tilde{Q}_{\mu \nu}^{(l+1)} (h^{(l)}) + \sum_{\mu \nu} \frac{1}{2} h_{\mu \nu}^{(l)} [Q^{(l)}]_{\mu \nu}^{-1} h_{\nu}^{(l)} \quad \text{for } l \in [L, L-1]
 $ (12)

[第8页，第12段]
其中$  A_{\mu \nu}^{(L)} = \sigma^{-4} (y_{\mu} - \tilde{f})(y_{\nu} - \tilde{f})^{-1} - [Q_f + \sigma^2 I_n]^{-1},  $ 和$  A^{(l)} = [Q^{(l)}]^{-1} (I_n - (h^{(l)} (h^{(l)})^{\top})_{\text{MF}} [Q^{(l)}]_{\mu \nu}^{-1})  $。后核自洽地定义为$  Q_f = \langle Q_f \rangle_{\text{MF}},  $ 和$  Q^{(l)} = \langle Q^{(l)} \rangle_{\text{MF}}  $ 对于$  l \in [L, L-1]  $。

[第8页，第13段]
值得注意的是，不同层之间的任何耦合仅通过静态平均场量，即预核和后核。

[第9页，第1段]
此外，所有神经元-神经元耦合（以及类似地，CNN 中的通道-通道耦合）都已被移除。

[第9页，第2段]
**层内解耦。** 尽管简化了层间耦合和层内神经元耦合，但对于除输出层之外的所有层，平均场作用仍然是非二次的。这种非线性以在数据点索引上大致全连接的方式耦合了同一神经元（在 CNN 情况下为通道）的所有 $  h^{(0)}  $ 变量。在原子和核物理中，类似的情况可以用自洽 Hartree-Fock 近似$ ^{46-49} $很好地描述。在我们的设定中，这种近似直接类似于变分高斯近似（VGA）。在补充材料（4）中，我们论证了在 $  K^{(l)}  $ 的对角线远大于非对角线元素的典型情况下，VGA 是良好受控的。技术上，我们通过逐阶微扰理论证明，VGA 近似所考虑的图支配了所有其他微扰理论图。在补充材料（3）中，我们还针对具有单个激活层的两层 CNN 的具体情况，使用不同的方法在 $  S_0 \gg 1  $ 时建立了这一点。我们进一步指出，VGA 对于深度线性 DNN 是精确的。

[第9页，第3段]
因此，我们现在寻找由核 $  K^{(l)}  $ 支配的高斯分布，该分布最接近上述非二次作用。在具有许多隐藏层的模型中，这导致对于 $  1 < l < L - 2  $ 出现以下“逆核偏移”行为

[第9页，第4段]
$ 
[K^{(l-1)}]_{\mu \nu} = [Q^{(l-1)}]_{\mu \nu} + \frac{2N_l}{N_{l-1}} \frac{\partial D_{KL}(K^{(l)})[Q^{(l)}]}{\partial K^{(l-1)}_{\mu \nu}} \tag{13}
 $

[第9页，第5段]
其中 $  l  $ 表示层索引，$  D_{KL}(A||B)  $ 是两个协方差矩阵为 $  A  $ 和 $  B  $ 的多元高斯分布之间的 Kullback-Leibler（KL）散度。如补充材料（1）所示，对于反对称激活函数，KL 散度的导数明确给出为 $  \text{Tr}[Q^{(l)}]^{-1}(K^{(l)} - Q^{(l)})[Q^{(l)}]^{-1}  $。对于非反对称的情况，见补充材料（5）。

[第9页，第6段]
**三层 CNN 模型定义**

[第9页，第7段]
对于“扩展到更深层 CNN 和真实世界数据集子集”一节中的分析，我们考虑一个学生 3 层 CNN，定义为

[第9页，第8段]
$ 
f(x) = \sum_{j=0}^{N-1} \sum_{c'=1}^{C_2} a_{cj} \phi(h_{cj}^{(2)}(x)) \\
h_{cj}^{(2)}(x) = \sum_{i=0}^{S_1-1} \sum_{c=1}^{C_1} v_{ci} \phi(h_{cji}^{(1)}(x)) \\
h_{cji}^{(1)}(x) = w_c \cdot x_{i+jS_1}
 $

[第9页，第9段]
其中 $  w_c, x_{i+jS_1} \in \mathbb{R}^{S_0}, a \in \mathbb{R}^{C_2 \times N}, v \in \mathbb{R}^{C_2 \times C_1 \times S_1}  $，输入向量 $  x \in \mathbb{R}^d  $ 且 $  d = N S_1 S_0  $，激活函数 $  \phi : \mathbb{R} \to \mathbb{R}  $ 逐元素应用。参见图 7 的图示。与之前类似，回归目标 $  (y_\mu)  $ 由随机教师 CNN $  (y_\mu = f'(x_\mu))  $ 生成，其架构与学生相同，只是 $  C_1 = C_2 = 1  $。此外，我们为学生选择了 $  S_0 = 50, S_1 = 30, N = 2, C_1 = C_2 = 100  $。我们用 * 下标表示教师权重和预激活。更多细节见补充信息第 2 节。

[第9页，第10段]
**使用 Langevin 型动力学的贝叶斯后验采样**

[第9页，第11段]
在本节中，我们给出关于用于从贝叶斯后验生成样本的算法的更多细节。我们使用带有权重衰减和外部白

[第9页，第12段]
**图 7 | 一个 3 层 CNN 架构。** 具有非重叠步长的图示。黑色方块表示每一层中的步长窗口。

[第9页，第13段]
高斯噪声。因此参数的离散时间动力学为

[第9页，第14段]
$ 
\theta_{t+1} - \theta_t = - \eta \left( \gamma \theta_t + \nabla_{\theta_t} \mathcal{L}(\theta_t, \theta_n) \right) + 2\sigma \sqrt{\eta} \xi_{t+1} \tag{15}
 $

[第9页，第15段]
其中 $  \theta_t  $ 是时间步 $  t  $ 时所有网络参数的向量，$  \gamma  $ 是权重衰减的强度（从贝叶斯角度看，它与先验参数方差成反比），$  \mathcal{L}(\theta_t, \theta_n)  $ 是作为 DNN 参数 $  \theta_t  $ 和数据函数的损失，$  \sigma  $ 是噪声幅度，$  \eta  $ 是学习率，$  \xi_{t,i} \sim \mathcal{N}(0,1)  $。当 $  \eta \to 0  $ 时，这些离散时间动力学收敛到由 $  \theta(t) = - \nabla_{\theta} \left( \frac{\gamma}{2} \| \theta(t) \|^2 + \mathcal{L}(\theta(t), \theta_n) \right) + 2\sigma \xi(t)  $ 给出的连续时间 Langevin 方程，其中 $  \langle \xi_i(t) \xi_j(t') \rangle = \delta_{ij} \delta(t - t')  $，使得当 $  t \to \infty  $ 时，DNN 参数 $  \theta  $ 将从参数空间中的平衡 Gibbs 分布 $  p(\theta | \theta_n)  $ 中采样。原则上，无论赋予参数的初始条件如何，这都是成立的。然而，在实践中，为了实现合理的收敛时间，我们设置了一个零均值且方差与贝叶斯先验匹配的随机初始条件。

[第9页，第16段]
这种用于从贝叶斯后验生成样本的算法对应于未调整 Langevin 算法（ULA）$ ^{50-52} $，并结合了权重衰减项。学习率、权重衰减和噪声水平（或 SGD 的小批量大小）等超参数可以在不同的训练协议中进行实验和比较，从而使我们的方法与实践者用于训练 DNN 的基于梯度的算法更紧密地联系在一起，同时也符合贝叶斯视角。虽然这种后验采样方法与其他更复杂的采样器（如 HMC$ ^{33} $）相比可能收敛较慢，但它更简单（例如没有 Metropolis 接受步骤，因此称为“未调整”），并且与普通 SGD 具有直观的对应关系，其中小批量噪声被替换为白加性噪声$ ^{31} $。在一些相当温和的条件下，ULA 已被证明具有良好的收敛性质$ ^{50} $。

对于所有 myrtle-5 实验，我们使用 $n=2048$、$C=256$ 和 ReLU 激活函数。训练参数（噪声和权重衰减）被缩放，使得 $\sigma^2=0.005$，且所有层在初始化时没有训练数据的情况下，权重方差相对于扇入为 2.0。

[第10页，第3段]
对于所有 FCN 实验，我们使用等宽度（$N_1=N_2$）和对应于方差 $\sigma_w^2=\sigma_3^2=2$（无训练数据）的权重衰减，采用常规缩放。对于 MF 缩放，我们取 $\sigma_4^2=2/N_2$。所有实验的目标均从 $N_1=N_2=1$ 的教师 CNN 中重新抽取一次。具体而言，在计算涌现尺度时，我们使用 $\sigma_4^2=2/256$，与 $N_2$ 无关。

[第10页，第4段]
**平衡采样。** 为了从训练后的 CNN 的平衡分布中获得弱相关样本，我们使用了以下过程。对于 2 层和 3 层 CNN，我们使用了自适应学习率调度器：在前 100 个 epoch 中，我们使用学习率 $lr_0/10$，然后将学习率提升至 $lr_0$。从第 5e3 个 epoch 开始，每 1e3 个 epoch 我们估计训练损失的波动并检查尖峰——即训练损失比过去 500 个 epoch 的标准差大五倍的事件。如果观察到尖峰，学习率降低 0.7 倍。此过程持续到连续 5e4 个 epoch 无任何事件发生。然后学习率再降低两倍并保持固定。来自这些最终阶段的样本被视为平衡样本。我们进一步验证了：(i) 使用此协议训练的不同初始化种子达到了相同的训练损失统计量。(ii) 在最终学习率降低后，训练损失没有进一步下降。对于若干次运行，我们还验证了将最后一次学习率降低再额外缩小 2 倍对损失没有明显影响。初始 $lr_0$ 为 $-1e-4$（相对于标准均值缩减 MSE 损失），最终学习率通常为 $-1e-5$。运行在第 3e5 个 epoch 终止。

[第10页，第5段]
对于在 CIFAR-10 上训练的 myrtle-5 CNN，我们首先使用上述过程运行了若干次 3e5 个 epoch 的实验，并检查了那些达到最低训练损失的运行。然后，我们基于这些更成功的实例生成了一个固定调度器，运行最多 4e5 个 epoch。我们再次验证了进一步降低最终学习率对训练损失没有明显影响，并且不同的种子达到相似的最终训练损失。这确保我们确实是从有效的平衡分布中采样。

[第10页，第6段]
对于 3 层 CNN 和 Myrtle-5，我们发现预激活的自相关时间在各层之间变化很大。读出层的自相关时间通常约为 1e3 个 epoch（在最低学习率下），而输入层的自相关时间可能达到 -1e6 或更大。为了克服这个问题，在分析这些更深层 DNN 的预激活时，我们分别对 3 层 CNN 和 Myrtle-5 采用了包含 98 个和 234 个不同初始化种子的集成。

[第10页，第7段]
对于 3 层 FCN，我们使用了一个固定调度器，从最大稳定学习率的 1/2 开始，并在第 100、1e5、1e6、3e6 个 epoch 时将学习率降低 2 倍，在第 4e6、5e6 个 epoch 时降低 4 倍（总共降低 128 倍）。平衡采样在 6e6 – 7e6 个 epoch 之间进行。

[第10页，第8段]
**状态方程的数值求解。** 对于 2 层 CNN，状态方程使用 Newton-Krylov 方法求解，该方法不需要显式梯度。为促进收敛，我们采用了退火过程：对于 $C-1e3$，我们使用 $\Sigma$ 的 GP 初始值（$x_0$）获得解。然后将优化结果用作下一个更低 $C$ 值的 $x_0$。使用 12 个 CPU 核心，此优化耗时数小时。在获得作为 $C$ 函数的 $\Sigma_{sy}$ 后，所得核 $[Q_t]_{ww}$ 被用于标准 GP 推断，以在测试集上获得 $f$。对于 3 层 FCN，我们使用了更高效的基于 JAX 的代码来生成 EoS 中涉及的核和核导数，但除此之外遵循相同的过程。优化在一个 Titan-X GPU 上耗时从几分钟到几小时不等，取决于参数。
