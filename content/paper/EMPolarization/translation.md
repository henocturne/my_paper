[第1页，第5段]
极化是社会系统中一种普遍存在的现象。实证研究记录了社交媒体上大量关于观点极化的证据，显示出一种典型的双极化模式，将个体划分为持有相反观点的两个群体。尽管已有共同演化网络模型被提出用于理解极化现象，但现有工作无法生成稳定的双极化结构。此外，一个能够捕捉支配极化动态的通用机制的定量且全面的理论框架仍未得到解决。在本快报中，我们发现了一个观点分布的普适标度律，其特征由一组标度指数描述。这些指数将社会系统分类为双极化相和去极化相。我们发现了支配极化动态的两个通用机制，并提出一个同时考虑观点动态和网络演化的共同演化框架。在对社会互动的若干通用假设下，我们发现稳定的双极化社群结构会自然地从共同演化动态中涌现。我们的理论解析地预测了两次相变，跨越三个不同的极化相，这与Facebook和博客圈数据集的实证观察一致。我们的理论不仅解释了实证观察到的标度律，还使我们能够定量预测标度指数。

[第1页，第7段]
近期发表的关于观点极化的讨论受到了广泛关注，极化是指观点对立程度随时间增加的过程[1–4]。实证研究观察到一种典型的两极化模式，即个体被分为观点截然对立的两组。例如，自由派与保守派政党之间的政治分歧反映了政治取向上的观点异质性。这些不同态度在社交媒体上被观察到[5–10]，发现最常分享的政治观点与大部分自由派或保守派人群一致，即观点两极化。另一方面，实证数据也显示某些系统存在去极化阶段，其中非政治领域的观点分布在中立状态附近达到峰值，并伴随显著方差[5]。

[第1页，第8段]
实证研究表明，回音室效应是社会网络中观点极化的基础[6,7,11,12]，提示志同道合的用户倾向于互动[5,6,13]。确实，观点极化与网络结构的共存意味着观点动态与网络动态之间的相互作用在极化中起着关键作用。尽管已有增长型共演化模型被提出以理解观点与网络结构之间的相互影响，但这些研究并未专门聚焦于观点极化[14–17]。

[第1页，第9段]
最近，有人提出了一种强化共演化模型来解释网络极化现象[18,19]。该强化模型（reinforcement model, RM）生成两种状态：一种是稳定的单极化（monopolarized）阶段，其中所有人都倾向于单边观点；另一种是全球共识（global consensus）阶段，所有人都持有相同的中立观点。尽管在数值上观察到了亚稳态的双极化（bipolarized）模式，但它仅暂时出现，并迅速退化为单极化模式。此外，其出现高度依赖于初始状态。

[第1页，第10段]
尽管RM模型的部分成功暗示了极化模式可能源于共同演化动力学，但现有模型与经验观察到的稳定两极分化模式之间的差异有着深刻的根源。实际上，现有的极化建模框架是同步模型的一种变体，其中当系统进入有序相时，个体同步到单一状态。然而，要捕捉两极分化结构，则需要不同的框架。此外，共同演化网络模型因观点与网络结构之间复杂的相互作用而著称地难以求解。因此，现有模型大多依赖数值模拟和定性近似，而一个能够解释经验观察到的两极分化模式的定量模型仍然缺失。

[第1页，第11段]
在本信中，我们报告了一个由一组标度指数刻画的普适标度律，用于经验性观点分布。这些指数将社会系统划分为极化（polarization）和去极化（depolarization）相。为解释这一发现，我们提出了两种普遍存在的极化动力学机制。（1）观点同质化（homogenization）：个体的观点受到其邻居的影响。

[第2页，第1段]
在社会网络中，个体倾向于趋同于相似观点[20–24]。(2) 同质性聚类（Homophily clustering）：社会连接随时间演化，个体倾向于与信念相似者建立联系。因此，相似个体聚集成簇[6–8,11]。

这两种机制导致网络演化与观点动力学相互纠缠。因此，我们提出了一个通用的共演化框架（coevolving framework），以捕捉观点动力学与网络演化之间的相互作用。我们找到了所提建模框架的精确解，并从解析上预测了实证数据中观察到的普适标度律。我们解析计算了所提模型的相图，预测了三个新的稳定相：(i) 极化（polarization）、(ii) 部分极化（partial polarization）和 (iii) 去极化（depolarization），其中极化和部分极化相均呈现稳定的双极化模式。据我们所知，我们是首个从解析上预测稳定双极化模式的共演化网络模型，并通过数值模拟和实证测量加以验证。

[第3页，第2段]
**建模框架（Modeling framework）。**—为了解释实证观察结果，我们考虑一个由 $N$ 个交互智能体（agent）组成的共演化网络（coevolving network），每个智能体具有一个在 $-1$ 到 $1$ 之间连续变化的观点 $s$。智能体之间的连接由邻接矩阵（adjacency matrix）$A$ 描述，其中矩阵元素 $A_{ij} = 1$ 或 $0$ 分别表示智能体 $i$ 与 $j$ 相连或不相连。智能体的观点及其之间的连接均在连续时间 $t$ 内演化。此外，我们要求观点动力学与网络演化相互耦合，满足两个内在机制：(1) *观点同质化（opinion homogenization）*，即智能体观点的变化受其邻居观点的影响，并倾向于向相似观点转变；(2) *同质性聚类*，描述当智能体持有相似观点时，社交连接更有可能建立。这两种机制通过观点与社交连接的共演化动态耦合。下面我们详细讨论所提出的共演化动力学。

[第3页，第3段]
**观点同质化。**—为了对观点同质化进行建模，我们假设观点动力学遵循

[第3页，第4段]
$$ds_i = \mu(s_i, \bar{s}, A)dt + \sigma(s_i)dW_i, \tag{2}$$

[第3页，第5段]
其中 $\bar{s} = (s_1, s_2, \ldots, s_N)$ 表示所有智能体的观点集合，$s_i$ 是智能体 $i$ 的观点。$A$ 是智能体的邻接矩阵，$W_i$ 是标准维纳过程（Wiener process）。$\mu$ 是漂移项（drift term），控制观点的平均变化；$\sigma$ 是扩散项（diffusion term），控制观点动力学的方差。此外，我们假设观点漂移 $\mu$ 依赖于智能体 $i$ 及其邻居的观点，满足

[第3页，第6段]
$$\mu_i = \sum_{\langle i,j \rangle} F(s_i, s_j) = \sum_{j=1}^{N} A_{ij} F(s_i, s_j), \tag{3}$$

[第3页，第7段]
其中 $\langle i,j \rangle$ 表示对 $i$ 的所有邻居的交互求和 [22,23,28–31]。成对作用力（pairwise force）$F(s_i, s_j)$ 量化了个体 $i$ 和 $j$ 之间的交互。观点同质化要求 $F(s, s) = 0$ 且 $\partial_s F(s, s') = s < 0$。另一方面，扩散项 $D(s) \equiv \sigma(s)^2 / 2$ 仅依赖于每个智能体自身的观点 $s$。观点的有界性要求在边界处扩散消失，即 $D(s = \pm 1) = 0$，这意味着泰勒展开（Taylor expansion）为 $D(s) = (\sigma(s)^2 / 2) = (\sigma_0^2 / 2)(1 - s^2) + O[(1 - s^2)^2]$。求解方程(2)可得到单智能体观点的时间演化

[第3页，第8段]
$$\frac{\partial P(s;t)}{\partial(\alpha t)} = -\frac{\partial}{\partial s} \int_{-1}^{1} F(s, s') Q(s, s';t) ds' + \frac{\partial^2}{\partial s^2} [D(s)P(s;t)], \tag{4}$$

[第3页，第9段]
其中积分项捕捉了邻居交互的影响，因为 $Q(s, s';t)$ 隐式依赖于底层网络 $A$。

[第3页，第10段]
**同质性聚类。**—为了对同质性聚类进行建模，我们假设持有相似观点的智能体更有可能建立连接。具体而言，智能体 $i$ 将以概率速率 $\gamma_+(s_i, s_j) / N$ 连接到一个未链接的智能体 $j$ 以构建新边，其中 $s_i$ 和 $s_j$ 分别是智能体 $i$ 和 $j$ 的观点。因子 $1 / N$ 保证了网络的稀疏性。同时，智能体 $i$ 将以概率速率 $\gamma_-(s_i, s_j)$ 与已链接的智能体 $j$ 断开连接，从而消除一条现有边。即，

[第3页，第11段]
$$dP[A_{ij}(0 \rightarrow 1)] = \frac{\gamma_+(s_i, s_j)}{N} dt, \tag{5a}$$

[第3页，第12段]
$$dP[A_{ij}(1 \rightarrow 0)] = \gamma_-(s_i, s_j)dt. \tag{5b}$$

[第3页，第13段]
为了捕捉同质性聚类，我们假设 $\gamma_+$ 依赖于智能体 $i$ 及其邻居 $j$ 的观点。这种依赖性导致网络演化与观点动力学相耦合。

[第3页，第14段]
然而，我们注意到在大多数社交媒体中，观点变化比网络演化慢得多。为了量化它们各自的相对时间尺度，我们将观点漂移 $F \rightarrow \alpha F$ 和扩散 $D \rightarrow \alpha D$ 乘以一个表征观点更新速率相对于网络演化的因子 $\alpha$ 进行重标度。根据 $\alpha$ 的幂展开，我们发现联合观点分布 $Q(s, s';t)$ 的时间演化满足

[第3页，第15段]
$$\frac{\partial Q(s, s';t)}{\partial t} = \gamma_+(s, s') P(s;t) P(s';t) - \gamma_-(s, s') Q(s, s';t) + O(\alpha), \tag{6}$$

[第3页，第16段]
其中 $O(\alpha)$ 项捕捉了高阶修正。我们将在下面的讨论中保持在 $\alpha \rightarrow 0$ 的极限，即网络绝热演化（adiabatically），在此绝热近似（adiabatic approximation）下 $O(\alpha)$ 将被省略。

[第3页，第17段]
**稳态解（Stationary solution）。**—下面我们将聚焦于所提出框架的稳态解。方程(6)导出了稳态联合观点分布 $Q_{st}(s, s') = (\gamma_+(s, s') / \gamma_-(s, s')) P_{st}(s) P_{st}(s')$，其中 $P_{st}(s)$ 是稳态观点分布。将其代入方程(4)可得 $\int_{-1}^{1} K(s, s') P_{st}(s') ds' = \ln[D(s) P_{st}(s)]$，其中核（kernel）$K(s, s') \equiv \int(\gamma_+(s, s') F(s, s') / \gamma_-(s, s') D(s)) ds$。当 $s \rightarrow \pm 1$ 时，我们发现 $[\int_{-1}^{1} \kappa_+(s') P_{st}(s') ds'] \ln(1 \mp s) \sim \ln[(1 \mp s) P_{st}(s)]$，其中 $\kappa_+(s') \equiv (\gamma_+(s, s') F(\pm 1, s') / \gamma_-(s, s') \sigma_0^2)$。因此，我们的理论预测了普适的

[第4页，第1段]
标度律 $P_{\text{st}}(s) \sim (1 \mp s)^{\delta_{\pm}}$，其中指数 $\delta_{\pm} = \int_{-1}^{1} \kappa_{\pm}(s') P_{\text{st}}(s') ds' - 1$，与在真实世界网络（real-world networks）中发现的标度律（1）一致（见补充材料 [26]，解析解）。这一发现表明，该普适标度律对于共演化网络（coevolving networks）而言相当普遍，并且在很大程度上独立于微观细节。

[第4页，第2段]
**观点-拓扑关联（Opinion topology correlation）。** 方程（6）揭示了网络结构与观点之间的潜在关联（见补充材料 [26]，解析解）。将方程（4）和（5）与方程（6）结合，可得到归一化联合观点分布 $R(s, s') = (Q(s, s')) / (P(s)P(s')) = (\gamma_{+}(s, s')) / (\gamma_{-}(s, s'))$。由于联合观点分布 $Q(s, s')$ 统计的是观点分别为 $s$ 和 $s'$ 的两个智能体（agent）之间连接的边数，因此，观点为 $s$ 的智能体的期望度（expected degree）为 $\bar{k}(s) = \int_{-1}^{1} Q(s'|s) ds' = \int_{-1}^{1} (Q(s, s')) / (P(s)) ds' = \int_{-1}^{1} ds' P_{\text{st}}(s') (\gamma_{+}(s', s)) / (\gamma_{-}(s', s))$，这使我们能够预测网络度量 $\bar{k}$ 与观点 $s$ 之间的关联。

[第4页，第3段]
**最小模型（Minimal model）。** 为了将我们的理论与实证数据进行比较，下面我们将聚焦于所提出框架的一个最小实现。具体而言，我们采用线性观点动力学模型 [22,23]，$F(s, s') = \lambda(s' - s)$，其中 $\lambda$ 是控制观点变化速率的常数。我们还假设边的出生率和死亡率满足 $\gamma_{\pm}(s, s') = r_{\pm}(1 + J_{\pm}ss')$，其中 $|J_{\pm}| \leq 1$ 量化了同质性聚类（homophily clustering）的强度，即相似个体建立联系的趋势。我们找到了该最小模型的核（kernel）$K(s, s') = g \int ((1 + J_{\pm}ss') / (1 + J_{-}ss')) ((2(s' - s)) / (1 - s^2)) ds$ 的显式形式，其中参数 $g \equiv (\lambda / \sigma_0^2)(r_{+} / r_{-})$。这里，$\lambda / \sigma_0^2$ 代表观点同质化速率（opinion homogenization rate），$r_{+} / r_{-}$ 是网络连接的出生-死亡比率（birth-death ratio）。参数 $g$ 整合了观点动力学和网络动力学的相互作用强度。结合方程（4）和（6），我们求解了最小模型（$\langle s \rangle \neq 0$）的 $P(s)$，发现我们的预测与实证数据吻合 [图 2(a)–2(c)，见补充材料 [26]，最小模型]。需要注意的是，最小模型也能生成如图 2(a)–2(c) 所示的不对称 $P(s)$ 分布。然而，在实证数据上测得的平均观点 $\langle s \rangle$ 非常接近于零，这意味着相应的 $P(s)$ 可以用对称分布很好地近似。为简便起见，在下面的讨论中我们将只关注对称情形（$\langle s \rangle = 0$）。

[第4页，第4段]
为了探索不同的相（phase），我们在固定 $J_{+}$ 和 $J_{-}$ 的情况下，对不同 $g$ 值进行了数值模拟。图 1(b) 展示了一个包含 2000 个节点的模拟最小模型，与图 1(a) 所示的实证网络在定性上具有相似性。图 3(a) 显示，在较小的 $g$ 值（$g \approx 0.9$）下，会出现双极化的 U 形观点分布 $P(s)$。通过逐渐增加观点变化速率，我们发现 $P(s)$ 从 U 形转变为 M 形，这表明出现了部分极化（partial polarization）。当 $g$ 值足够大时（$g \approx 2.4$），$P(s)$ 转变为去极化（depolarized）的倒 U 形分布。为了量化不同的相，我们定义了一个序参量（order parameter）$s_{\text{max}} = |\arg \max_s P(s)|$ 作为最可能的观点。我们发现，在去极化相中 $s_{\text{max}} = 0$ [图 3(c)]，在极化相中 $s_{\text{max}} = 1$ [图 3(a)]。对于部分极化相，$s_{\text{max}}$ 的取值范围在 0 到 1 之间 [图 3(b)]。图 3(d) 绘制了 $s_{\text{max}}$ 作为 $g$ 的函数，表明存在两个相变（phase transition）。第一个相变发生在 $g_* \approx 1.3$ 处，此时 $s_{\text{max}}$ 偏离 1，表明系统从极化转变为部分极化。第二个相变发生在 $g_{**} \approx 1.78$ 处，此时 $s_{\text{max}}$ 消失，表明系统在部分极化和去极化之间发生转变。总体而言，减小 $g$ 会使系统趋向极化。事实上，较小的观点同质化速率会使观点远离同质化状态，从而走向极化。另一方面，较大的出生-死亡比率会降低不同智能体之间建立连接的机会；因此，相似的智能体倾向于聚集在一起，其观点趋于同质化，从而导致极化。

[第4页，第5段]
为了探索观点-拓扑关联，我们在图 2(f) 中绘制了预测的归一化联合观点分布 $R(s, s') = (\gamma_{+}(s, s')) / (\gamma_{-}(s, s')) = (r_{+}(1 + J_{+}ss')) / (r_{-}(1 + J_{-}ss'))$，显示出在左下角和右上角附近存在两个相反的聚集域，这与实证观察一致 [图 2(e)]。图 2(d) 描绘了 $\bar{k}(s)$ 的解析预测，与实证测量结果相符。需要注意的是，实证数据显示中性个体存在一个小峰值，这意味着这些用户的期望度比我们的理论预测要大。这种差异可能是由于存在一小部分政治中立但吸引了来自双方大量连接的独立媒体所致。

[第5页，第2段]
**相图（Phase diagram）。**—由于我们的理论成功捕捉了极化相和去极化相，人们可能会想知道建模参数如何控制不同的相。为简化起见，我们仅关注对称情形，即$ \langle s \rangle = 0 $。如上所述，指数$ \delta < 0 $对应极化相，而$ \delta > 0 $对应部分极化相和去极化相。因此，当指数$ \delta = 0 $时出现极化与部分极化之间的转变，由此得到$ g_s^{-1} + (J_+ - J_-)f(J_-) = 1 $，其中$ f(J_-) = (1 + J_-) \int_{-1}^{1} ds' (s'^2 / (1 - J_-^2 s'^2)) P_{st}(s') $。

[第5页，第3段]
对于部分极化相与去极化相之间的转变，由于对称性，在$ s = 0 $处的一阶导数消失，即$ P'(0) = 0 $。然而，对于M形的$ P(s) $，二阶导数$ P''_{st}(0) > 0 $，而对于倒U形的$ P(s) $，$ P''_{st}(0) < 0 $。因此，当二阶导数消失时发生转变，即$ P''_{st}(0) = 0 $。将$ P'_{st}(0) = 0 $和$ P''_{st}(0) = 0 $代入方程(4)，我们得到$ g_{s*}^{-1} + (J_+ - J_-) \langle s^2 \rangle = 1 $，其中$ \langle s^2 \rangle $是意见分布的方差。图4绘制了由我们的模型预测的相图。实曲线分隔了对应于不同相的区域。我们根据从数据拟合得到的建模参数，在图中标出了经验数据集。该图显示，博客圈（blogosphere）和FBHC位于极化相，而FBSC位于去极化相。

[第5页，第4段]
总之，我们从经验上发现了意见分布的普适标度律（scaling law），该定律由一组标度指数刻画，使我们能够量化真实社会系统的不同极化相。我们提出了一个共演化网络极化动力学的通用框架，其中意见动力学和网络演化基于两个要素耦合。与现有的RM模型相比，我们的模型预测了稳定的双极化相和去极化相。特别是，我们的理论解析地找到了双极化的意见分布和网络结构，这与经验观察一致。此外，我们的框架提供了共演化网络动力学的精确解，这不仅解释了观察到的标度律，还预测了包含三个不同相的相应相图。

[第5页，第5段]
另一方面，我们的解析解是在绝热近似（adiabatic approximation）下得到的。我们将寻求一般解留待未来研究。我们的理论提供了一个可应用于其他领域的通用框架。例如，通过引入$ s_i = \cos(\theta_i) $，该框架能够对涉及背景变化的非线性耦合振子进行建模[32–34]。最重要的是，我们的结果可能对跨学科理解人类社会产生影响，包括社会科学和政治学。
